1. 项目名称

Ana Tilim

维吾尔文：

ئانا تىلىم

核心含义：

我的母语 / My Mother Tongue

项目定位不是普通词典，也不是单纯背单词工具，而是一个面向维吾尔语学习者的现代语言学习平台。

2. 产品定位

Ana Tilim 是一个：

面向中文用户，以及“会说维吾尔语但不会熟练读写”的用户，结合图片记忆、听力、书写和键盘输入的维吾尔语学习产品。

产品借鉴两个方向：

Droplets：图片词汇、短时学习、轻游戏化、快速复习

ScriptPad: Language Writing：字母描摹、书写练习、录音对比、键盘输入、自定义练习

最终形成自己的特色：

看图认识 → 听发音 → 认识字母 → 描摹书写 → 学会连接 → 键盘输入 → 放进句子使用

3. 目标用户

第一类：完全不会维吾尔语的人

主要是：

中文母语者

想系统学习维吾尔语的人

对维吾尔语和文化感兴趣的人

学习路线：

字母 → 发音 → 单词 → 句子 → 场景表达

第二类：会说但不会读写的人

主要是：

能听懂部分维吾尔语

家庭中使用维吾尔语

但不熟悉维吾尔文字母、拼写和键盘输入的人

学习路线：

字母识别 → 字母连接 → 拼写 → 键盘 → 阅读 → 听写

第三类：已有基础的人

通过简单测试后，直接进入：

错题复习

阅读

拼写

听力

键盘输入

句子练习

4. 产品形式

第一阶段不做原生 App。

先制作：

手机优先、可以安装到主屏幕的 PWA 网站

用户可以：

通过链接打开

添加到手机主屏幕

像 App 一样全屏运行

保存学习进度

使用部分离线课程

后续再包装成 iOS 和 Android App

这样更适合新手，也更适合依赖 Codex 开发。

20. 视觉设计

不完全复制 Droplets，也不做成儿童化产品。

推荐配色：

主色：深靛蓝

辅色：湖蓝

背景：暖白

强调色：柔和金色

正确提示：青绿色

错误提示：低饱和珊瑚红

视觉元素：

圆角卡片

大字号维吾尔文

简洁插图

清晰层级

流畅过渡动画

文化纹样只用于课程封面、分隔线和徽章

避免：

每个页面都使用复杂民族纹样

过度卡通
