# Ana Tilim 课程内容冻结清单

冻结日期：2026-08-11
内容状态：**已冻结**

## 发布范围

- 海外版：12 个单元。
- 国内版：11 个单元；仅保留已批准的版本差异，其余学习功能与海外版同步。
- 32 个字母，126 个真实位置字形。
- 34 个字母组合。
- 206 个词汇学习条目。
- 128 个练习条目。
- 192 个语法、基础句型、对话、故事、谚语与名言学习句。
- 6 篇已经负责人同意写入课程的阿凡提小故事。

## 录音范围

- 554 个真人录音目标，服务 590 个课程内容绑定；完全相同的文本允许复用同一录音。
- 本次正式导入 29 个录音：27 个新内容录音，2 个修正后的替换录音。
- `ئەرزىمەيدۇ / erzimeydu / 不客气、不用谢` 已替代错误的 `مەرھابا / merhaba`。
- 用户要求删除的 `خەير / xeyr` 不再属于发布词汇。
- `ژ` 和 `كۆرۈشكىچە` 使用本次选定的新录音。
- 两条文本完全相同的新学习句复用已有真人录音，不重复制造文件。

## 冻结后规则

1. 不再为了“数量更多”持续新增单元或题目。
2. 后续工作以缺陷修复、可用性、无障碍、同步、安全和翻译质量为主。
3. 如果母语审校或可靠来源确认某个词、句子或录音有误，可定点修正；这属于修复，不是课程扩张。
4. 程序检查可确认字段、ULY、稳定 ID、内容顺序、文件和音频绑定；不冒充母语者的逐条语感审核。
