# 课程数据编辑与审校说明

## 这份文件是做什么的

这份说明给项目创建者、审校者和以后帮忙开发的人看。

现在原型里的主要课程内容已经拆成几个小文件：

```text
prototype/course-data/alphabet-data.js
prototype/course-data/combo-data.js
prototype/course-data/vocab-data.js
prototype/course-data/practice-data.js
prototype/course-data/reading-data.js
```

也就是说，大多数“课程里显示什么字母、什么组合、什么词、什么练习”的内容，都先在对应的小文件里改。

`prototype/course-data.js` 现在是总入口。它负责把这些小文件合并给页面使用，平时不需要改。

`prototype/app.js` 主要负责页面、按钮、进度、错题、音频播放和交互逻辑。没有特殊需要时，不要为了改一个词或一句中文说明去改 `app.js`。

## 先记住四个大块

课程数据里最重要的是这几组数据：

| 文件 | 数据名 | 对应内容 | 什么时候改 |
| --- | --- | --- | --- |
| `prototype/course-data/alphabet-data.js` | `alphabetGroups` | 第一单元：认识字母 | 调整字母分组、学习目标、字母顺序 |
| `prototype/course-data/combo-data.js` | `comboGroups` | 第二单元：组合与词组入门 | 调整字母组合、三字母慢读、基础称呼预览 |
| `prototype/course-data/vocab-data.js` | `vocabGroups` | 第四单元：日常用语与词汇 | 调整问候、人称、家庭称呼、数字等词条 |
| `prototype/course-data/practice-data.js` | `practiceGroups` | 第三单元：听说与书写强化 | 调整听音、跟读、书写、错题复习目标 |
| `prototype/course-data/reading-data.js` | `readingUnits` | 第五到第九单元：基础句型、对话、小故事、文化人物主题学习句、谚语与智慧短句 | 调整阅读内容、中文翻译和来源审校 |

第一单元文件里还有两个相关数据：

| 数据名 | 对应内容 |
| --- | --- |
| `alphabetLetters` | 32 个字母总表，用于字母库和总顺序 |
| `letterDetails` | 每个字母的详细说明、四种写法、提示语 |

## 哪些字段可以放心改

这些字段主要是给学习者看的文字，比较适合审校后直接修改：

| 字段 | 作用 | 示例 |
| --- | --- | --- |
| `title` | 单元或小组标题 | `家庭、基础称呼` |
| `goal` | 学习目标 | `只练词形，不设唯一答案` |
| `value` | 维吾尔语内容 | `ئانا` |
| `latin` | 拉丁转写或读音提示 | `ana` |
| `meaning` | 中文预览含义 | `妈妈、母亲` |
| `hint` | 学习提示 | `先记词形，不急着排除 ئاپا。` |
| `tip` | 词条页面里的补充提示 | `和 ئانا 比较：中间是 پ。` |
| `standardNote` | 标准语说明 | `候选标准主词，需确认。` |
| `variantNote` | 变体说明 | `用户已提醒它也可表示妈妈。` |
| `reviewStatus` | 审校状态文字 | `待母语者审校` |
| `audioStatus` | 音频状态文字 | `音频待录，暂不播放` |
| `lesson` | 旧说明字段，当前页面不显示 | `学习母语，也是在认识自己的文化。` |

## 哪些字段不要随便改

这些字段会被页面、按钮、进度、音频路径或测试使用。除非知道影响范围，否则不要随便改：

| 字段 | 为什么要小心 |
| --- | --- |
| `id` | 页面用它找到对应字母、词条或练习；改了可能导致按钮找不到内容 |
| `letterId` | 字母音频用它匹配字母 |
| `kind` | 页面用它判断这是字母、组合、词汇还是练习 |
| `mode` | 练习中心用它判断听音、跟读、手写、键盘输入或复习 |
| `readingKind` | 阅读单元用它区分句型、对话、故事、名言或谚语 |
| `parts` | 页面用它拆分字母和组合 |
| `items` | 每组里的具体学习内容；可以增删，但要保持格式完整 |
| `file` | 真人音频文件名；文件不存在时播放会失败 |

如果只是改中文说明、提示语、审校备注，通常不要改 `id`。

## 编辑一个词条时怎么做

以第三单元家庭称呼为例，词条大概长这样：

```js
{
  id: "ana-family",
  value: "ئانا",
  latin: "ana",
  meaning: "妈妈、母亲",
  standardNote: "候选标准主词，需确认。",
  variantNote: "和 ئاپا 的关系需母语者确认。",
  reviewStatus: "待母语者审校"
}
```

如果母语者确认中文说明需要改，优先改：

- `meaning`
- `standardNote`
- `variantNote`
- `acceptableAnswer`
- `testPolicy`
- `reviewStatus`

不要为了改“妈妈、母亲”去改 `id: "ana-family"`。

## 标准维吾尔语原则

主线统一按标准维吾尔语设计。

南疆、北疆、家庭口语和地区说法可以记录，但要放到备注里，不要直接混成唯一正确答案。

特别注意这些基础称呼：

| 词形 | 当前处理方式 |
| --- | --- |
| `ئانا` | 候选标准主词，待母语者确认 |
| `ئاپا` | 可能是家庭称呼或变体，待母语者确认 |
| `ئاتا` | 候选标准主词，待母语者确认 |
| `دادا` | 可能是家庭称呼或变体，待母语者确认 |

这些词在正式审校前，不要设置唯一答案。

## 审校状态怎么写

建议统一使用这些文字：

| 状态 | 什么时候用 |
| --- | --- |
| `待母语者审校` | 还没有确认，当前默认状态 |
| `通过` | 母语者确认可以进入正式课程 |
| `需修改` | 词形、转写、中文或说明需要改 |
| `只展示不考核` | 可以给学习者看，但不作为标准答案题目 |
| `变体保留` | 是地区、家庭或口语说法，需要和标准主词分开 |
| `待二审` | 第一位审校者不确定，需要第二位确认 |

如果不确定，先保留 `待母语者审校`。

## 音频状态怎么写

当前项目只保留真人音频。已接入文件可以在原型里播放，但正式发布前仍要完成母语者审听。

建议统一使用这些文字：

| 状态 | 什么时候用 |
| --- | --- |
| `音频待录` | 还没有审听通过的可播放音频 |
| `真人音频已录制` | 真人已录好，但还没接入页面 |
| `真人音频已接入` | 页面已经能播放真人音频 |
| `需重新录制` | 读音、噪音、口音或文字有问题 |

不要把未审听的录音当成最终标准发音；发现问题时标成 `需重新录制`。

## 新增或审校阅读内容时怎么做

第五到第九单元在 `prototype/course-data/reading-data.js` 里。

阅读内容分五类：

| 单元 | 数据特点 | 审校重点 |
| --- | --- | --- |
| 第五单元：基础句型 | 每个小课是 3 到 5 个短句型 | 确认句子自然、语法和中文翻译准确 |
| 第六单元：对话小剧场 | 每个小课是 4 到 6 句双人对话 | 确认日常说法自然、礼貌等级合适 |
| 第七单元：小故事 | 每个小课是 5 到 8 句超短故事 | 确认句子简单、顺序自然 |
| 第八单元：文化人物主题学习句 | 每个人物小课有 3 条非直接引语学习句 | 必须明确标注为主题学习句；没有可靠出处时不得写成人物原话 |
| 第九单元：维吾尔语谚语与智慧短句 | 每个主题小课有 3 条谚语或学习短句 | 区分传统谚语与编写的智慧短句，必要时改成标准、自然的现代维吾尔语 |

人物引语最容易误传。没有找到可靠来源前，只能作为“主题学习句（非原文引语）”，不要把学习版译句改成“已审校原文”。

## 新增一个词条时怎么做

先复制同一组里已有的一个词条，然后只改必要字段。

最少要检查这些字段：

```js
{
  id: "new-word-id",
  value: "维吾尔语词形",
  latin: "转写",
  meaning: "中文预览",
  theme: "所属主题",
  parts: ["拆分", "内容"],
  reviewStatus: "待母语者审校"
}
```

新增后要确认：

- `id` 不能和其他词条重复。
- `value` 是从右到左显示的维吾尔语。
- `latin` 不确定时先写候选，不要当最终标准。
- `meaning` 不确定时写中文预览，不要当最终答案。
- `reviewStatus` 先写 `待母语者审校`。
- 新词正式进入听音题前，要先审校，再准备音频。

## 新增一个练习时怎么做

第四单元的练习在 `prototype/course-data/practice-data.js` 的 `practiceGroups` 里。

每个练习组有自己的 `mode`：

| `mode` | 练习类型 |
| --- | --- |
| `listen` | 听音辨认 |
| `repeat` | 跟读练习 |
| `write` | 书写 |
| `keyboard` | 键盘 |
| `review` | 错题复习 |

新增练习时，优先复用前面单元已经出现过的字母、组合或词形。

第四单元原则是：不急着加新词，先把第一到三单元内容练熟。

`tests/course-data-integrity.test.mjs` 是内容完整性检查器。它会检查：

- 字母、组合、词汇、练习有没有重复 `id`
- 每个分组有没有内容
- 常用字段有没有缺失
- 第三单元词条是不是还标着 `待母语者审校`
- 真人音频清单是不是和课程数据数量、文件名、转写一致

如果看到页面空白，最常见原因是：

- 少了逗号
- 引号没有成对
- `[` 或 `{` 没有关闭
- 改了 `id`，但其他地方还在找旧 id
- 音频文件名写了，但文件还没有放进去

## 最安全的工作方式

1. 一次只改一小组内容。
2. 不确定的内容继续写 `待母语者审校`。
3. 标准主词、家庭说法、地区说法分开写。
4. 没有审听通过前，音频只标 `音频待录`。
5. 改完打开原型检查页面。
6. 确认没问题后，再继续下一组。
