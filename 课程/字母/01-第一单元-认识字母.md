# 第一单元：认识字母

## 文件用途

这份文件是 Ana Tilim 字母阶段第一单元的完整课程草稿。

第一单元名称：

```text
认识字母
```

第一单元目标不是背单词，而是让用户先完整认识 32 个标准维吾尔文字母。第二单元开始，才逐步加入字母组合、简单词组和基础表达。

## 审校状态

整体状态：`待母语者审校`

需要重点审校：

- 32 个字母顺序是否符合标准教学习惯
- 转写提示是否适合新手
- 四种形态是否展示正确
- 连接规则是否表述清楚
- 发音提示是否自然准确
- 书写提示是否符合实际教学
- 键盘练习是否符合目标输入法布局

## 标准语原则

本单元统一按标准维吾尔语字母教学设计。

本单元不正式教授词义，不把家庭 / 基础称呼、地区说法或家庭口语作为答案。所有示例只用于观察字母形态、点位、连接和输入。词组学习从第二单元开始。

## 第一单元学习目标

学完本单元后，用户应该能够：

- 按截图顺序认出 32 个字母
- 知道维吾尔文从右到左书写
- 知道字母有独立、词首、词中、词尾形态
- 区分点在上方、下方、无点和多点的字母
- 区分几个形状相似的字母组
- 知道哪些字母后面通常不继续连接
- 能用键盘输入单个目标字母
- 准备进入第二单元的组合 / 词组学习

## 截图顺序字母表

用户看到的总字母表按这个顺序：

```text
ئا ئە ب پ ت ج چ
خ د ر ز ژ س ش
غ ف ق ك گ ڭ ل
م ن ھ ئو ئۇ ئۆ ئۈ
ۋ ئې ئى ي
```

这个顺序用于总目录、进度、复习和查找。

## 分组课程草稿

### 组 1：点位骨架 ب / پ / ت / ن

学习目标：

- 把看起来相似的主体放在一起
- 点多点少没关系，先一起比较
- 知道下方一个点是 `ب`
- 知道下方三个点是 `پ`
- 知道上方两个点是 `ت`
- 知道上方一个点是 `ن`

对比重点：

| 字母 | 点位 |
| --- | --- |
| `ب` | 下方一个点 |
| `پ` | 下方三个点 |
| `ت` | 上方两个点 |
| `ن` | 上方一个点 |

认字母练习：

```text
哪个字母是下方一个点？
答案：ب
```

```text
哪个字母是上方两个点？
答案：ت
```

形态练习：

```text
请选择 ب 的词中形：ـبـ
请选择 ت 的词尾形：ـت
```

键盘练习：

```text
ب
پ
ت
ن
```

### 组 2：弯形 ج / چ / خ

学习目标：

- 认识三个相似弯形字母
- 区分下方一个点、下方三个点、上方一个点

对比重点：

| 字母 | 点位 |
| --- | --- |
| `ج` | 下方一个点 |
| `چ` | 下方三个点 |
| `خ` | 上方一个点 |

认字母练习：

```text
哪个字母是下方三个点的弯形？
答案：چ
```

形态练习：

```text
请选择 خ 的词首形：خـ
请选择 ج 的词中形：ـجـ
```

发音提示：

- `j`、`ch`、`x` 只做入门提示。
- `x` 的真实发音需要真人音频，不用中文强行精确对应。

### 组 3：不后连 د / ر / ز / ژ

学习目标：

- 知道这些字母可以接收前面的连接
- 知道这些字母后面通常不继续连接
- 理解为什么文字中间会出现断开

对比重点：

| 字母 | 点位 / 形状 |
| --- | --- |
| `د` | 无点短形 |
| `ر` | 无点弧形 |
| `ز` | 上方一个点 |
| `ژ` | 上方三个点 |

连接练习：

```text
观察 با + د：前面可以连到 د，但 د 后面不继续连接。
```

形态练习：

```text
请选择 ز 接在前一个字母后的形态：ـز
```

提示：

- 这一组要反复告诉用户：不是所有字母后面都会连起来。
- 看到断开不一定是错误，可能是字母本身的连接规则。

### 组 4：齿形 س / ش

学习目标：

- 认识无点齿形 `س`
- 认识上方三点齿形 `ش`
- 知道二者都可以连接后面的字母

对比重点：

| 字母 | 重点 |
| --- | --- |
| `س` | 没有点 |
| `ش` | 上方三个点 |

认字母练习：

```text
哪个字母有上方三个点？
答案：ش
```

形态练习：

```text
请选择 س 的词中形：ـسـ
```

书写提示：

- 先看连续齿形。
- 不要求第一版做精准手写评分。

### 组 5：圆形和上点 غ / ف / ق

学习目标：

- 认识三个带圆形结构的字母
- 区分 `غ`、`ف`、`ق`
- 发音提示只做辅助，正式课程必须使用真人音频

对比重点：

| 字母 | 重点 |
| --- | --- |
| `غ` | 上方一个点，发音较难 |
| `ف` | 上方一个点，形体较小 |
| `ق` | 上方两个点，发音较难 |

认字母练习：

```text
哪个字母是上方两个点？
答案：ق
```

形态练习：

```text
请选择 ف 的词首形：فـ
请选择 غ 的词尾形：ـغ
```

教学提示：

- 这一组发音不要急着要求用户准确模仿。
- 第一版重点是认形和听辨。

### 组 6：k 系 ك / گ / ڭ

学习目标：

- 认识 `ك`
- 认识 `گ`
- 认识 `ڭ`
- 知道这三者形态相近，但发音不同

对比重点：

| 字母 | 转写 | 重点 |
| --- | --- | --- |
| `ك` | k | k 系基础形 |
| `گ` | g | 形体和 `ك` 相近 |
| `ڭ` | ng | 鼻音，后续听力重点 |

认字母练习：

```text
请选择 ng：ڭ
```

形态练习：

```text
请选择 گ 的词中形：ـگـ
请选择 ڭ 的词尾形：ـڭ
```

教学提示：

- `ڭ` 对很多新手不容易，需要慢慢听。
- 第一单元先认字母，不做精准发音评分。

### 组 7：无点常用辅音 ل / م / ھ

学习目标：

- 认识三个无点常用辅音
- 用整体轮廓区分它们
- 继续复习连接形态

对比重点：

| 字母 | 重点 |
| --- | --- |
| `ل` | 竖形和收笔 |
| `م` | 圆形 |
| `ھ` | 开口形 |

认字母练习：

```text
哪个字母有明显圆形？
答案：م
```

形态练习：

```text
请选择 ل 的词首形：لـ
请选择 ھ 的词中形：ـھـ
```

键盘练习：

```text
ل
م
ھ
```

### 组 8：尾部易混 ۋ / ي

学习目标：

- 认识 `ۋ`
- 认识 `ي`
- 知道 `ۋ` 后面通常不继续连接
- 知道 `ي` 可以连接后面的字母
- 先把它们从元音组里单独拿出来比较

对比重点：

| 字母 | 转写 | 重点 |
| --- | --- | --- |
| `ۋ` | w / v | 后面通常不继续连接 |
| `ي` | y | 下方两个点，可以连接 |

认字母练习：

```text
请选择 w / v：ۋ
请选择 y：ي
```

形态练习：

```text
请选择 ي 的词中形：ـيـ
请选择 ۋ 接在前一个字母后的形态：ـۋ
```

教学提示：

- `ۋ` 和元音字母视觉上会有联系，但第一单元先按字母身份分清。
- `ي` 后续会和 `ئى` 继续对比。

### 组 9：元音 1 ئا / ئە

学习目标：

- 认识词首元音常见的 `ئ`
- 认识 `ئا`
- 认识 `ئە`
- 知道这两个是最先学的元音入口

对比重点：

| 字母 | 转写 | 重点 |
| --- | --- | --- |
| `ئا` | a | `ئ` + `ا` |
| `ئە` | e | `ئ` + `ە` |

认字母练习：

```text
请选择 a：ئا
请选择 e：ئە
```

形态练习：

```text
哪个是 ئا 接在前一个字母后的形态？
答案：ـا
```

教学提示：

- `ئ` 的完整输入规则放到元音专项和键盘专项里慢慢教。
- 这组先解决“为什么词首有 ئ”这个新手问题。

### 组 10：元音 2 ئو / ئۇ / ئۆ / ئۈ

学习目标：

- 认识 `ئو`
- 认识 `ئۇ`
- 认识 `ئۆ`
- 认识 `ئۈ`
- 把四个圆唇元音放在一起听和认

对比重点：

| 字母 | 转写 | 重点 |
| --- | --- | --- |
| `ئو` | o | `ئ` + `و` |
| `ئۇ` | u | `ئ` + `ۇ` |
| `ئۆ` | ö | `ئ` + `ۆ` |
| `ئۈ` | ü | `ئ` + `ۈ` |

认字母练习：

```text

请选择 ö：ئۆ
```

形态练习：

```text
哪个是 ئۇ 接在前一个字母后的形态？

```

教学提示：

- 这组最好配真人音频。
- 中文提示不能替代真实元音。
- 第一单元只要求认字母，不做精准发音评分。

### 组 11：元音 3 ئې / ئى

学习目标：

- 认识 `ئې`
- 认识 `ئى`
- 把它们和 `ي` 继续区分

对比重点：

| 字母 | 转写 | 重点 |
| --- | --- | --- |
| `ئې` | ë | 元音入口 |

用户进入第二单元前，应该能做到：

- 看到 32 字母表时，能大致读出每个字母
- 能按截图顺序找到某个字母
- 能把相似字母放在一起比较
- 能解释 `ب` / `پ` / `ت` / `ن` 的点位差异
- 能解释 `س` / `ش` 的区别
- 能说出 `د` / `ر` / `ز` / `ژ` 后面通常不继续连接
- 能选择常见字母的词首、词中、词尾形
- 能输入单个目标字母

## 第二单元衔接

第二单元开始加入：

- 两字母组合
- 三字母组合
- 高频音节
- 简单词组
- 听音选择
- 键盘输入

第二单元仍然要慢，不直接进入大量词汇。

建议从已经最熟悉的字母开始：

```text
ئا ئە ب پ ت ن ل م س ش
```

先做组合，再做词组，再进入家庭 / 基础称呼等主题。
