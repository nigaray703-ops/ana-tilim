# 第二组字母：م、ن、ت、س

## 文件用途

这份文件是 Ana Tilim 字母阶段第二组课程草稿。

第二组只做四个字母：

- `م`
- `ن`
- `ت`
- `س`

这一组接在第一组 `ئا`、`ب`、`ل` 后面，用来继续练习点位、连接和简单组合辨认。第二组仍然是字母课，不进入家庭 / 基础称呼主题。

## 审校状态

整体状态：`待母语者审校`

需要重点审校：

- 发音提示是否自然准确
- 四种形态是否展示正确
- 连接规则是否表述清楚
- 书写提示是否符合实际教学
- 简单组合是否适合作为字母阶段练习
- 键盘提示是否符合目标输入法布局

## 标准语原则

本组继续按标准维吾尔语字母教学设计。

本组不正式教授词义，也不把地区说法、家庭口语或称呼词作为答案。所有示例只用于观察字母形态和连接。等字母阶段完成后，再单独进入家庭 / 基础称呼课程。

## 本组学习目标

学完本组后，用户应该能够：

- 认识 `م`、`ن`、`ت`、`س`
- 知道 `ن` 是上方一个点
- 知道 `ت` 是上方两个点
- 知道 `س` 没有点，但有连续齿形
- 知道这四个字母都可以接收前方连接，也可以连接后面的字母
- 能看懂每个字母的独立、词首、词中、词尾形态
- 能做简单点位辨认题
- 能输入 `م`、`ن`、`ت`、`س` 和简单组合

## 推荐课程顺序

1. 复习：从右到左、连接、点位
2. 字母 `م`
3. 字母 `ن`
4. 字母 `ت`
5. 字母 `س`
6. 对比练习：`ن` 和 `ت`
7. 对比练习：`س` 和带点字母
8. 键盘：输入 `م`、`ن`、`ت`、`س`
9. 小测：选择正确字母、选择正确形态、输入目标组合

## 字母 1：م

### 基本身份

| 字段 | 内容 |
| --- | --- |
| 主字母 | `م` |
| 转写 | `m` |
| 初步类型 | 辅音 |
| 课程位置 | 第二组第 1 个 |
| 审校状态 | 待母语者审校 |

### 教学重点

`م` 适合放在第二组开头，是因为它没有点，可以让用户先从整体轮廓和连接形态入手。

对新手可以先说：

> `م` 的完整形状有明显的圆形部分；连接时，它会变成更短的连接形。

### 形态表

| 位置 | 形态 | 教学说明 |
| --- | --- | --- |
| 独立 | `م` | 单独出现时的完整形状 |
| 词首 | `مـ` | 后面伸出连接线 |
| 词中 | `ـمـ` | 左右都连接 |
| 词尾 | `ـم` | 接在前一个字母后，后面结束 |

### 连接规则

教学草稿：

- `م` 可以连接后面的字母。
- 当前面有字母连过来时，`م` 也可以接收连接。
- `م` 的形态变化比较明显，适合用来复习“四种形态”。

示例观察：

```text
ما
```

可以解释为：

- `م` 在开头，使用词首形 `مـ`
- 后面接 `ا`
- `ا` 后面通常不继续连接

### 发音提示

中文辅助提示：

- 可先接近理解为汉语拼音或英语里的 `m`。
- 发音提示只是帮助入门，正式课程以真人音频为准。

### 书写提示

教学草稿：

- 注意圆形部分不要写得太扁。
- 注意连接线和基线的位置。
- 词首和词中形更适合先看清连接，不急着追求漂亮。

### 键盘练习

练习 1：

```text
م
```

练习 2：

```text
ما
```

练习 3：看组合拆分

```text
م + ا → ما
```

说明：

- 这里先作为字母组合练习。
- 不把它当作正式词汇课。

### 易混淆点

第一版可提醒：

- `م` 没有点。
- 不要和带点字母混在一起判断。
- 重点先看圆形部分和连接位置。

## 字母 2：ن

### 基本身份

| 字段 | 内容 |
| --- | --- |
| 主字母 | `ن` |
| 转写 | `n` |
| 初步类型 | 辅音 |
| 课程位置 | 第二组第 2 个 |
| 审校状态 | 待母语者审校 |

### 教学重点

`ن` 的核心识别点是上方一个点。

对新手可以先说：

> 看到上方一个点、主体像弧线时，可以先想到 `ن`。

### 形态表

| 位置 | 形态 | 教学说明 |
| --- | --- | --- |
| 独立 | `ن` | 单独出现时的完整形状，上方一个点 |
| 词首 | `نـ` | 后面伸出连接线，点仍在上方 |
| 词中 | `ـنـ` | 左右都连接，点仍在上方 |
| 词尾 | `ـن` | 接在前一个字母后，后面结束 |

### 连接规则

教学草稿：

- `ن` 可以连接后面的字母。
- 当前面有字母连过来时，`ن` 可以出现在词中或词尾。
- 判断 `ن` 时不要只看弧线，要看上方一个点。

示例观察：

```text
نا
```

可以解释为：

- `ن` 在开头，所以用词首形 `نـ`
- 后面接 `ا`

### 发音提示

中文辅助提示：

- 可先接近理解为汉语拼音或英语里的 `n`。
- 正式课程以真人音频为准。

### 书写提示

教学草稿：

- 主体弧线要平稳。
- 上方一点不能漏。
- 连接形里，点仍然是辨认关键。

### 键盘练习

练习 1：

```text
ن
```

练习 2：

```text
نا
```

练习 3：看组合拆分

```text
ن + ا → نا
```

说明：

- 这里先作为字母组合练习。
- 不把它当作正式词汇课。

### 易混淆点

重点对比：

- `ن`：上方一个点
- `ت`：上方两个点
- `ب`：下方一个点

练习题可以让用户只判断点的位置和数量，不要求立刻记住所有词义。

## 字母 3：ت

### 基本身份

| 字段 | 内容 |
| --- | --- |
| 主字母 | `ت` |
| 转写 | `t` |
| 初步类型 | 辅音 |
| 课程位置 | 第二组第 3 个 |
| 审校状态 | 待母语者审校 |

### 教学重点

`ت` 的核心识别点是上方两个点。

对新手可以先说：

> `ت` 和 `ن` 很像，但 `ت` 上面有两个点。

### 形态表

| 位置 | 形态 | 教学说明 |
| --- | --- | --- |
| 独立 | `ت` | 单独出现时的完整形状，上方两个点 |
| 词首 | `تـ` | 后面伸出连接线，两个点在上方 |
| 词中 | `ـتـ` | 左右都连接，两个点在上方 |
| 词尾 | `ـت` | 接在前一个字母后，后面结束 |

### 连接规则

教学草稿：

- `ت` 可以连接后面的字母。
- 当前面有字母连过来时，`ت` 也可以接收连接。
- `ت` 的点位和 `ن` 的点位很适合一起练。

示例观察：

```text
تا
```

可以解释为：

- `ت` 在开头，使用词首形 `تـ`
- 后面接 `ا`

### 发音提示

中文辅助提示：

- 可先接近理解为汉语拼音或英语里的 `t`。
- 不要把中文提示当成精确发音。
- 正式课程以真人音频为准。

### 书写提示

教学草稿：

- 主体形态和连接方式先按 `ن` 的对比来学。
- 两个点要清楚，不能写成一个点。
- 点的位置在上方。

### 键盘练习

练习 1：

```text
ت
```

练习 2：

```text
تا
```

练习 3：看组合拆分

```text
ت + ا → تا
```

说明：

- 这里先作为形态和键盘练习。
- 不把它当作正式词汇课。

### 易混淆点

重点对比：

- `ت`：上方两个点
- `ن`：上方一个点
- `ب`：下方一个点
- `پ`：下方三个点，第三组再详细讲

## 字母 4：س

### 基本身份

| 字段 | 内容 |
| --- | --- |
| 主字母 | `س` |
| 转写 | `s` |
| 初步类型 | 辅音 |
| 课程位置 | 第二组第 4 个 |
| 审校状态 | 待母语者审校 |

### 教学重点

`س` 没有点，主要靠连续齿形识别。

对新手可以先说：

> `س` 像一串连续的小齿，重点看齿形，不看点。

### 形态表

| 位置 | 形态 | 教学说明 |
| --- | --- | --- |
| 独立 | `س` | 单独出现时的完整形状 |
| 词首 | `سـ` | 后面伸出连接线 |
| 词中 | `ـسـ` | 左右都连接 |
| 词尾 | `ـس` | 接在前一个字母后，后面结束 |

### 连接规则

教学草稿：

- `س` 可以连接后面的字母。
- 当前面有字母连过来时，`س` 也可以接收连接。
- `س` 没有点，所以不能用点位判断，要看齿形。

示例观察：

```text
سا
```

可以解释为：

- `س` 在开头，使用词首形 `سـ`
- 后面接 `ا`

### 发音提示

中文辅助提示：

- 可先接近理解为汉语拼音或英语里的 `s`。
- 正式课程以真人音频为准。

### 书写提示

教学草稿：

- 注意连续齿形的数量和节奏。
- 不要把齿形写成一条完全平直的线。
- 连接形要保持基线稳定。

### 键盘练习

练习 1：

```text
س
```

练习 2：

```text
سا
```

练习 3：看组合拆分

```text
س + ا → سا
```

说明：

- 这里先作为字母组合练习。
- 不把它当作正式词汇课。

### 易混淆点

后续可以和这些字母对比：

- `ش`：上方三个点，第三组再详细讲
- `ص`：不在标准 32 字母主线里，第一版不主动引入

第二组只要求用户先记住：

- `س` 没有点
- `س` 有连续齿形

## 本组练习设计

### 练习 1：认字母

题目示例：

```text
请选择字母 ن
```

选项：

- `ن`
- `ت`
- `ب`

教学目的：

- 让用户看点的位置和数量。

### 练习 2：点位判断

题目示例：

```text
哪个字母是上方两个点？
```

推荐答案：

```text
ت
```

选项：

- `ن`
- `ت`
- `ب`

### 练习 3：看形态

题目示例：

```text
下面哪个是 س 的词中形式？
```

选项：

- `سـ`
- `ـسـ`
- `ـس`

### 练习 4：看连接

题目示例：

```text
观察 نا，哪个字母连接到 ا？
```

推荐答案：

```text
ن
```

### 练习 5：键盘输入

目标输入 1：

```text
ما
```

按键顺序：

```text
م → ا
```

目标输入 2：

```text
نا
```

按键顺序：

```text
ن → ا
```

目标输入 3：

```text
سا
```

按键顺序：

```text
س → ا
```

说明：

- 输入顺序按实际文字顺序。
- 显示方向为从右到左。
- 这些目标先作为字母组合，不作为正式词汇答案。

## 后续衔接

第二组结束后，用户已经接触了：

- 第一组：`ئا`、`ب`、`ل`
- 第二组：`م`、`ن`、`ت`、`س`

此时用户可以做更清楚的点位对比：

- 下方一点：`ب`
- 上方一点：`ن`
- 上方两点：`ت`
- 无点齿形：`س`
- 无点圆形：`م`

建议下一步进入第三组：

- `پ`
- `ج`
- `چ`
- `ش`

第三组重点处理点的数量、点在上方还是下方，以及形近字选择题。
