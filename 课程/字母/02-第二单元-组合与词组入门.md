# 第二单元：组合与词组入门

## 单元定位

第二单元从“认识单个字母”过渡到“把字母连起来看”。

本单元采用混合版：

1. 先学习两字母组合。
2. 再学习三字母慢读。
3. 最后少量预览基础称呼词形。

基础称呼只做词形预览，不作为正式答案。所有词义、标准主词、地区 / 家庭口语变体，都必须经过维吾尔语母语者审校后再进入正式课程。

## 单元目标

用户完成第二单元后，应该能够：

- 知道维吾尔文组合从右往左读
- 能把两字母组合拆开看
- 能把三字母组合慢慢读出来
- 能用键盘输入简单组合
- 知道词义和变体需要审校，不把预览内容当最终答案

## 学习分组

### 组 1：开口组合 ا

目标：把熟悉辅音接到 `ا` 后面，先形成最简单的开口组合。

| 组合 | 转写提示 | 学习重点 |
| --- | --- | --- |
| `با` | ba | `ب` 接 `ا` |
| `پا` | pa | `پ` 的下方三个点 |
| `تا` | ta | `ت` 的上方两个点 |
| `نا` | na | `ن` 的上方一个点 |
| `لا` | la | `ل` 接 `ا` 的样子 |
| `ما` | ma | `م` 的连接形 |

说明：这些先作为组合练习，不作为正式词义。

### 组 2：轻声组合 ە

目标：把同一批辅音换成 `ە`，比较结尾符号变化。

| 组合 | 转写提示 | 学习重点 |
| --- | --- | --- |
| `بە` | be | 和 `با` 对比 |
| `پە` | pe | 和 `پا` 对比 |
| `تە` | te | 和 `تا` 对比 |
| `نە` | ne | 和 `نا` 对比 |
| `لە` | le | 和 `لا` 对比 |
| `مە` | me | 和 `ما` 对比 |

说明：正式发音以后需要真人音频。

### 组 3：三字母慢读

目标：从两字母过渡到三字母，只练拆分、慢读和输入。

| 组合 | 转写提示 | 拆分 |
| --- | --- | --- |
| `بال` | bal | `ب` + `ا` + `ل` |
| `مان` | man | `م` + `ا` + `ن` |
| `نان` | nan | `ن` + `ا` + `ن` |
| `تال` | tal | `ت` + `ا` + `ل` |

说明：这些组合如果作为词汇使用，必须另做词义审校。第二单元先不把它们当词汇考。

### 组 4：基础称呼预览

目标：让用户知道字母组合会变成词形，但不急着把称呼做成正式词汇课。

| 词形 | 转写提示 | 中文预览 | 审校状态 |
| --- | --- | --- | --- |
| `ئانا` | ana | 妈妈 / 母亲 | 标准主词待母语者审校 |
| `ئاپا` | apa | 妈妈 / 家庭称呼变体 | 变体身份待母语者审校 |
| `ئاتا` | ata | 爸爸 / 父亲 | 标准主词待母语者审校 |
| `دادا` | dada | 爸爸 / 家庭称呼变体 | 变体身份待母语者审校 |

重要原则：

- `ئانا` 不能直接排除 `ئاپا`。
- `ئاتا` 不能直接排除 `دادا`。
- 标准主词、地区说法、家庭口语和可接受答案要分开。
- 第二单元只预览词形，正式家庭 / 基础称呼单元后续单独设计。

## 练习设计

### 练习 1：组合辨认

题目示例：

```text
哪一个读作 ba？
```

选项：

```text
با
پا
تا
نا
```

### 练习 2：拆分组合

题目示例：

```text
بال 可以拆成哪几个部分？
```

推荐提示：

```text
ب + ا + ل
```

### 练习 3：键盘输入

目标：

```text
请输入：مان
```

用户可以：

- 直接点击完整组合快捷键
- 或者按拆分键慢慢输入

### 练习 4：词形预览

题目示例：

```text
请选择 ana 的词形（妈妈 / 母亲：待审校）
```

说明：这类题只练词形和转写，不把中文含义当最终审校结果。

## 完成标准

用户完成第二单元后，应该能做到：

- 输入 `با`、`ما`、`نا`、`لا`
- 看出 `ا` 和 `ە` 结尾的区别
- 拆分 `بال`、`مان`、`نان`、`تال`
- 看到 `ئانا`、`ئاپا`、`ئاتا`、`دادا` 时知道它们是待审校的基础称呼预览
- 准备进入第三单元的正式基础词组与主题词
