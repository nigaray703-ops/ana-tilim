# Ana Tilim 字母基础路线

## 文件用途

这份文件是 Ana Tilim 第一阶段“字母基础”的主路线。

它回答三个问题：

- 用户先学什么，再学什么
- 32 个标准维吾尔文字母如何按截图顺序展示
- 第一单元如何按相似字母分组学习，第二单元如何开始加入组合 / 词组

这不是最终教材文案，而是课程设计稿。涉及发音、示例、连接规则和书写细节的内容，必须经过维吾尔语母语者审校后才能进入正式课程。

## 标准语原则

Ana Tilim 主线统一按标准维吾尔语设计。

南疆、北疆、家庭口语和地区说法可以保留，但不直接混入主答案。后续进入词汇课程时，每个词条应区分：

- 标准维吾尔语主词
- 中文含义
- 拉丁转写
- 地区/口语变体
- 可接受答案
- 只展示不考核的备注
- 审校状态

第一单元只讲字母、形态、发音提示、点位、连接规则和键盘位置。第二单元开始加入字母组合、简单词组和非常基础的表达。家庭 / 基础称呼放在字母认识之后单独设计。

## 总体学习原则

### 1. 展示顺序按标准字母表

用户看到的 32 个字母表，按截图顺序排列：

```text
ئا ئە ب پ ت ج چ
خ د ر ز ژ س ش
غ ف ق ك گ ڭ ل
م ن ھ ئو ئۇ ئۆ ئۈ
ۋ ئې ئى ي
```

这个顺序用于：

- 字母表页面
- 总进度
- 复习目录
- 用户查找字母

### 2. 教学顺序按相似性分组

新手真正学习时，不机械按一行一行推进，而是把相似的字母放在一起比较：

- 形状相似
- 点的位置相似
- 点的数量相似
- 是否连接后面相似
- 元音结构相似

这样用户更容易记住差别，不会把字母当成 32 个孤立符号死背。

### 3. 第一单元只认识字母

第一单元名为：

```text
认识字母
```

第一单元不正式教授词义，不把家庭称呼作为答案，不做地区说法考核。

第一单元允许使用简单字母组合做观察，例如：

```text
با
لا
ما
نا
```

这些只用于看连接和输入，不作为正式词汇课。

### 4. 第二单元开始加入组合 / 词组

第二单元名为：

```text
字母组合与词组入门
```

从第二单元开始，课程可以逐步加入：

- 两字母组合
- 三字母组合
- 高频音节
- 简单词组
- 最基础表达

但第二单元也要遵守标准语原则：主答案统一按标准维吾尔语，变体放备注，不直接混入考核答案。

## 字母阶段总目标

用户完成字母阶段后，应该能够：

- 知道维吾尔文从右到左书写
- 知道字母会根据位置变形
- 理解独立、词首、词中、词尾四种形态
- 认识 32 个标准维吾尔文字母
- 知道元音开头常见 `ئ` 的作用
- 能区分几个容易混淆的点位字母
- 能知道哪些字母后面通常不继续连接
- 能做基础描摹和键盘输入
- 能进入第一批词组 / 词汇主题，而不是死记单个字母

## 单元路线

### 第一单元：认识字母

目标：先完整认识 32 个字母。

第一单元学习内容：

- 标准字母顺序
- 字母名称 / 转写提示
- 元音和辅音的初步区别
- 点的位置和数量
- 独立、词首、词中、词尾形态
- 连接与断开
- 基础书写观察
- 键盘位置和单字母输入

第一单元相似分组：

| 组 | 字母 | 学习重点 |
| --- | --- | --- |
| 1 | `ب` / `پ` / `ت` / `ن` | 同一类主体形态，点多点少都放一起比较 |
| 2 | `ج` / `چ` / `خ` | 相似弯形，重点看点在上方还是下方 |
| 3 | `د` / `ر` / `ز` / `ژ` | 后面通常不继续连接，重点看断开 |
| 4 | `س` / `ش` | 齿形对比，重点看有没有三点 |
| 5 | `غ` / `ف` / `ق` | 圆形和上方点，发音提示要谨慎 |
| 6 | `ك` / `گ` / `ڭ` | k 系形态对比 |
| 7 | `ل` / `م` / `ھ` | 无点常用辅音，重点看整体轮廓 |
| 8 | `ۋ` / `ي` | 容易和元音、尾部形态混淆的常用字母 |
| 9 | `ئا` / `ئە` | 元音 1：先认识最基础的词首元音入口 |
| 10 | `ئو` / `ئۇ` / `ئۆ` / `ئۈ` | 元音 2：圆唇元音放在一起比较 |
| 11 | `ئې` / `ئى` | 元音 3：后段元音和 `ي` 继续区分 |

第一单元完成标准：

- 用户能按截图顺序认出 32 个字母
- 用户能说出 `ب` / `پ` / `ت` / `ن` 的点位差异
- 用户能说出 `س` / `ش` 的区别
- 用户能说出 `د` / `ر` / `ز` / `ژ` 后面通常不继续连接
- 用户能选择常见字母的正确形态
- 用户能用键盘输入单个目标字母

### 第二单元：字母组合与词组入门

目标：在已经认识字母的基础上，开始把字母连成组合，再慢慢进入词组。

第二单元学习内容：

- 开口两字母组合：`با` / `پا` / `تا` / `نا` / `لا` / `ما`
- `ە` 结尾两字母组合：`بە` / `پە` / `تە` / `نە` / `لە` / `مە`
- 三字母慢读：`بال` / `مان` / `نان` / `تال`
- 基础称呼词形预览：`ئانا` / `ئاپا` / `ئاتا` / `دادا`
- 组合辨认
- 键盘输入
- 字母到词形的过渡

第二单元原则：

- 只使用第一单元已学字母
- 先做组合，再做词组
- 词义和变体必须等审校后再作为正式答案
- 基础称呼只在第二单元后半做词形预览，正式家庭 / 基础称呼单元后续单独设计
- `ئانا` / `ئاپا`、`ئاتا` / `دادا` 需要分清标准主词、变体和可接受答案，不能只设一个唯一说法

### 第三单元：基础词组与主题词

目标：开始进入真正的日常表达，但先采用审校优先方式。

第三单元学习内容：

- 问候：`ياخشىمۇسىز` / `رەھمەت` / `خوش` / `ئەسسالامۇ ئەلەيكۇم`
- 我 / 你 / 他：`مەن` / `سىز` / `سەن` / `ئۇ` / `بىز`
- 家庭 / 基础称呼：`ئانا` / `ئاپا` / `ئاتا` / `دادا`
- 数字 1-5：`بىر` / `ئىككى` / `ئۈچ` / `تۆت` / `بەش`
- 词形辨认
- 键盘输入
- 词库审校字段理解

第三单元原则：

- 所有词条当前都是候选词条
- 中文含义只做预览，不作为最终答案
- 标准语主词、地区 / 家庭口语变体、可接受答案和只展示不考核备注必须分开
- 家庭 / 基础称呼必须区分标准主词和变体，例如“妈妈”“爸爸”不能只设置一个唯一说法
- 审校表放在 `课程/词库/基础词库审校表.md`

### 第四单元：听说与书写强化

目标：把字母、组合、词组变成可听、可说、可写、可输入的能力。

第四单元原则：

- 不加新词，只复习第一到三单元已经出现过的内容
- 真实音频还没有录制，听音和跟读先做页面流程
- 所有音频按钮当前都标记为 `真人音频待录制`
- 第三单元词义仍然待母语者审校，第四单元不把中文含义作为最终答案
- 第一单元的单字母描摹页继续保留

第四单元学习内容：

- 听音辨认：`ب` / `با` / `مەن`
- 跟读练习：`ئا` / `نا` / `رەھمەت`
- 书写 / 键盘：`ن` / `مان` / `ئانا`
- 错题复习：`س` / `سىز` / `بەش`
- 练习结果页

第四单元完成标准：

- 用户能从底部 `书写` 进入第四单元练习中心
- 用户能打开四个练习组
- 用户能完成听音选择、跟读确认、描摹输入和复习卡查看
- 用户能看到本轮结果
- 后续真实音频、录音跟读、错题自动记录和本地进度保存可以继续接入

第四单元详细文档放在 `课程/字母/04-第四单元-听说与书写强化.md`。

## 每个字母课程结构

每个字母建议按同一结构整理：

1. 字母身份

   主字母、转写、类型、是否元音、是否高频。

2. 四种形态

   独立、词首、词中、词尾。不能连接后续字母的字母，需要特别标记。

3. 发音提示

   用中文辅助理解，但不要把中文提示当成精确发音。正式版需要真人音频。

4. 书写提示

   起笔、收笔、点的位置、连接方向。第一版先写文字提示，后续再做动画。

5. 键盘练习

   找键、点键、输入单字母、输入简单组合。

6. 易混淆内容

   形近字、点位、发音接近项。

7. 示例组合

   第一单元只放少量字母组合，不进入完整词汇教学。

8. 审校状态

   所有字母条目都标注 `待母语者审校`，审校通过后再变成正式课程。

## MVP-0 内容边界

MVP-0 做：

- 第一单元 `认识字母`
- 32 个字母总顺序
- 相似字母分组
- 一条最小学习闭环
- 字母识别、形态展示、描摹、键盘输入
- 第二单元入口预告

MVP-0 不做：

- 家庭称呼正式词汇课
- 地区说法考核
- 精准发音评分
- 精准手写识别
- 大型词库
