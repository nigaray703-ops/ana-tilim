# 第一组字母：ئا、ب、ل

## 文件用途

这份文件是 Ana Tilim 字母阶段第一组课程草稿。

第一组只做三个字母：

- `ئا`
- `ب`
- `ل`

这三个字母用于建立最小学习闭环：认识字母、看形态、理解连接、描摹书写、键盘输入，然后为后续词汇 `بالا` 做准备。

## 审校状态

整体状态：`待母语者审校`

需要重点审校：

- 发音提示是否自然准确
- 书写提示是否符合实际教学
- 连接规则是否表述清楚
- 示例词是否适合放在字母阶段
- 键盘提示是否符合目标输入法布局

## 标准语原则

本组只讲字母，不正式教授家庭称呼。

后续进入家庭 / 基础称呼时，必须按标准维吾尔语设计主词，并把南疆、北疆、家庭口语等说法放入变体字段。比如“妈妈”“爸爸”这类词不能只写一个说法，也不能在字母阶段提前当作唯一标准答案。

## 本组学习目标

学完本组后，用户应该能够：

- 知道 `ئا` 是第一组里的元音入口
- 知道 `ب` 和 `ل` 是可以连接后续字母的辅音
- 看懂 `ب` 的四种形态
- 看懂 `ل` 的四种形态
- 理解 `ئا` / `ا` 后面通常不会继续连接
- 能描摹 `ب`
- 能在键盘里输入 `ب`、`ا`、`ل`
- 能识别组合示例 `بالا`

## 推荐课程顺序

1. 入门：从右到左
2. 字母 `ئا`
3. 字母 `ب`
4. 字母 `ل`
5. 组合观察：`ب` + `ا` + `ل` + `ا` → `بالا`
6. 描摹：先描 `ب`
7. 键盘：输入 `ب`、`ا`、`ل`、`ا`
8. 小测：选择正确字母、选择正确形态、输入目标组合

## 字母 1：ئا

### 基本身份

| 字段 | 内容 |
| --- | --- |
| 主字母 | `ئا` |
| 转写 | `a` |
| 初步类型 | 元音 |
| 课程位置 | 第一组第 1 个 |
| 审校状态 | 待母语者审校 |

### 教学重点

`ئا` 适合作为第一个字母，是因为它能自然引出一个重要概念：

> 维吾尔语中，词首元音前常见 `ئ` 作为承载符号。

对新手不要一开始讲太多术语，可以先说：

> 看到 `ئا` 时，先把它当成一个开头的 “a” 音来认识。以后学元音时，再详细讲 `ئ` 的作用。

### 形态表

| 位置 | 形态 | 教学说明 |
| --- | --- | --- |
| 独立 | `ئا` | 词首或单独展示时常见 |
| 词首 | `ئا` | 作为词首元音入口 |
| 词中 | `ـا` | 前面有字母连过来时，显示为连接后的 `ا` |
| 词尾 | `ـا` | 词尾接在前一个可连接字母后 |

### 连接规则

教学草稿：

- `ئا` / `ا` 可以接收前一个字母的连接。
- `ئا` / `ا` 后面通常不继续连接下一个字母。
- 所以在组合里，它常常造成视觉上的“断开”。

示例观察：

```text
بالا
```

可以解释为：

- `ب` 连接到后面的 `ا`
- `ا` 后面不继续连接
- `ل` 重新开始连接到最后的 `ا`

### 发音提示

中文辅助提示：

- 可以先接近理解为汉语“啊”的开口音。
- 这只是入门提示，不等于精准发音。
- 正式课程需要真人音频。

### 书写提示

教学草稿：

- 先认识 `ئ` 和 `ا` 的组合。
- 不要求第一课就把 `ئ` 的所有用法讲完。
- 写 `ا` 时注意竖直感和收笔。

### 键盘练习

第一版键盘练习可以先输入：

```text
ا
ئا
```

注意：

- 虚拟键盘里可以先出现 `ا`。
- `ئ` 的输入规则后续在元音专项里详细设计。

### 易混淆点

- `ئا` 和单独的 `ا`：先按课程阶段区分，不要一开始讲太复杂。
- `ئ` 在词首和词中作用不同：放到后续元音专项。

### 示例使用

字母阶段示例：

```text
بالا
```

这里只作为字母组合观察，不正式进入词汇课。

## 字母 2：ب

### 基本身份

| 字段 | 内容 |
| --- | --- |
| 主字母 | `ب` |
| 转写 | `b` |
| 初步类型 | 辅音 |
| 课程位置 | 第一组第 2 个 |
| 审校状态 | 待母语者审校 |

### 教学重点

`ب` 是适合早期学习的辅音：

- 形状清楚
- 下方有一个点
- 可以连接后续字母
- 能用于后续示例 `بالا`

对新手可以先说：

> 看到下面一个点、像小船一样的形状，可以先想到 `ب`。

### 形态表

| 位置 | 形态 | 教学说明 |
| --- | --- | --- |
| 独立 | `ب` | 单独出现时的完整形状 |
| 词首 | `بـ` | 后面伸出连接线 |
| 词中 | `ـبـ` | 左右都连接 |
| 词尾 | `ـب` | 接在前一个字母后，后面结束 |

### 连接规则

教学草稿：

- `ب` 可以连接后面的字母。
- 当前面有字母连接过来时，`ب` 可以出现在词中或词尾。
- 形态变化主要看它在词里的位置。

示例观察：

```text
با
```

可以解释为：

- `ب` 在开头，所以用词首形 `بـ`
- 后面接 `ا`

### 发音提示

中文辅助提示：

- 可先接近理解为英语 `b` 或汉语拼音里不送气的 `b`。
- 发音提示只是帮助入门，正式课程以真人音频为准。

### 书写提示

教学草稿：

- 主体像一条平稳的弧线。
- 点在下方，点的位置不能丢。
- 词首和词中形会更扁、更像连接线上的小弧。

第一版描摹重点：

- 看参考字
- 沿着主体弧线描
- 最后确认下方一点

### 键盘练习

练习 1：

```text
ب
```

练习 2：

```text
با
```

练习 3：

```text
بالا
```

### 易混淆点

后续可和这些字母对比：

- `پ`：下方三个点
- `ت`：上方两个点
- `ن`：上方一个点

第一课只提示“点的位置和数量很重要”，不一次塞进所有形近字。

### 示例使用

字母组合示例：

```text
بالا
```

说明：

- 此处只观察 `ب` 在词首如何连接。
- 不在本课正式教授词义。

## 字母 3：ل

### 基本身份

| 字段 | 内容 |
| --- | --- |
| 主字母 | `ل` |
| 转写 | `l` |
| 初步类型 | 辅音 |
| 课程位置 | 第一组第 3 个 |
| 审校状态 | 待母语者审校 |

### 教学重点

`ل` 适合放在第一组，是因为：

- 形状相对简单
- 可以连接后续字母
- 和 `ب`、`ا` 可以组成后续示例 `بالا`

对新手可以先说：

> `ل` 像一根竖线带着向下的收笔，连接时会伸出线和后面的字母连起来。

### 形态表

| 位置 | 形态 | 教学说明 |
| --- | --- | --- |
| 独立 | `ل` | 单独出现时的完整形状 |
| 词首 | `لـ` | 后面伸出连接线 |
| 词中 | `ـلـ` | 左右都连接 |
| 词尾 | `ـل` | 接在前一个字母后，后面结束 |

### 连接规则

教学草稿：

- `ل` 可以连接后面的字母。
- 如果前面有字母连过来，也可以接收连接。
- 在 `لا` 里，`ل` 会连接到后面的 `ا`。

示例观察：

```text
لا
```

可以解释为：

- `ل` 在开头，使用词首形
- `ا` 接在后面，但 `ا` 后面不继续连接

### 发音提示

中文辅助提示：

- 可先接近理解为英语 `l` 的音。
- 中文里没有完全一样的对应，正式课程以真人音频为准。

### 书写提示

教学草稿：

- 注意竖线的高度。
- 注意下方收笔的弧度。
- 连接形中，前后的连接线要保持在同一基线附近。

### 键盘练习

练习 1：

```text
ل
```

练习 2：

```text
لا
```

练习 3：

```text
بالا
```

### 易混淆点

第一课暂不展开太多形近字。

后续可以和：

- `ا`
- `ك`
- `گ`

做形态对比。

### 示例使用

字母组合示例：

```text
بالا
```

说明：

- 此处只观察 `ل` 如何连接到后面的 `ا`。
- 不在本课正式进入家庭 / 基础称呼主题。

## 本组练习设计

### 练习 1：认字母

题目示例：

```text
请选择字母 ب
```

选项：

- `ب`
- `ل`
- `ا`

### 练习 2：看形态

题目示例：

```text
下面哪个是 ب 的词中形式？
```

选项：

- `بـ`
- `ـبـ`
- `ـب`

### 练习 3：看连接

题目示例：

```text
观察 بالا，中间为什么有断开？
```

推荐答案：

```text
因为 ا 后面通常不继续连接。
```

### 练习 4：描摹

第一版先描摹：

```text
ب
```

原因：

- 形状清楚
- 点位明显
- 适合演示“主体 + 点”

### 练习 5：键盘输入

目标输入：

```text
بالا
```

按键顺序：

```text
ب → ا → ل → ا
```

说明：

- 输入顺序按实际文字顺序。
- 显示方向为从右到左。
- 用户看到的光标和文字排列需要在产品中单独处理 RTL。

## 后续衔接

第一组结束后，不马上进入大量词汇。

建议先进入第二组：

- `م`
- `ن`
- `ت`
- `س`

等用户对字母形态和连接更熟悉后，再进入家庭 / 基础称呼主题。
