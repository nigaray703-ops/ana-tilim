# 基础词库审校表

## 用途

这张表记录第三单元的候选词条。

所有条目当前状态都是 `待母语者审校`。审校时需要逐条确认：

- 词形是否标准
- 中文含义是否准确
- 是否是标准主词
- 是否是地区 / 家庭口语变体
- 是否可以进入考核
- 是否只展示不考核
- 是否需要真人音频

## 审校后要补充的字段

审校完成后，每个词条需要补齐：

- 标准语主词：是 / 否
- 变体类型：无 / 地区 / 家庭口语 / 其他
- 可考核：是 / 否
- 可接受答案列表
- 只展示不考核说明
- 真人音频文件名
- 例句
- 最终中文释义
