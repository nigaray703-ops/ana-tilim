# Ana Tilim 本机录音工作台操作指南

这个工具只在你的 Mac 本机运行，用来审听、补录和安全导入 Ana Tilim 的真人音频。它不会上线网站、不会上传云端，也不会替你自动批准任何录音。

## 开始前

请在 Ana Tilim 项目根目录运行：

```bash
NODE='/Users/nigarayaskar/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node'
$NODE tools/start-recording-studio.mjs
```

终端会显示类似 `http://127.0.0.1:4175` 的本地地址，并会尝试用 Google Chrome 打开。若没有自动打开，请把终端显示的地址复制到 Chrome；地址必须是 `127.0.0.1`，不是公开网站地址。

第一次开始录音时，Chrome 会请求麦克风权限。请只在确认当前是自己的本机录音工作台时选择允许；不想录音时可以拒绝，仍可搜索、审听和整理现有录音。

## 录音与审听流程

1. 启动工作台

   使用上面的命令。若想只显示地址、不自动打开 Chrome，运行 `$NODE tools/start-recording-studio.mjs --no-open`。需要换端口时只可使用 `--port 0` 到 `--port 65535`，例如 `--port 4176`。

2. 允许麦克风权限

   点击某个目标的“开始录音”后，按 Chrome 提示允许麦克风。不要在不认识的网页或公开地址授予这项权限。

3. 用分类、搜索和状态筛选目标

   顶部可以按字母、组合、词汇、阅读或写法例词筛选；再输入维文、ULY、中文或英文来搜索；也可以只看“待审听”或“需要重录”。

4. 为同一个目标录制多条 take

   选择一个目标，开始录音并停止后保存。每次保存都会新增一条 take；不会覆盖原录音，也不会覆盖较早的 take。

5. 对比现有音频和 take

   在目标详情中分别播放“当前课程音频”和每一条 take，确认读音、停顿和音量。当前音频、草稿 take 和导入后的音频是不同的内容。

6. 批准一条 take，或保留当前音频

   如果新录音更好，明确点选那一条 take 的“批准”；这只更新本机工作区状态，还没有改课程文件。若现有课程音频正确，试听后把它标为 `approved-current`。发现问题则标为 `needs-rerecord`。

7. 预览导入

   点击“预览导入”查看将要替换的目标、旧文件校验值和新文件校验值。预览是只读的：不会写课程音频，不会创建备份，也不会删除任何文件。

8. 确认导入

   确认预览无误后，再执行“确认导入”。这一步才会把已批准的 take 写入课程音频位置；系统会先为每个旧文件创建可恢复备份。

9. 试听导入后的课程文件，再按需完成一条替换

   导入后先播放该目标的“当前课程音频”，确认实际生产文件可播放。只有试听成功后，才可选择“确认新版并删除这一条旧版备份”。该动作一次只处理一个稳定 ID 对应的一份已核对备份；不需要时可保留备份。

10. 了解草稿、备份和日志的位置

   草稿 take、状态、备份、失败导入产物和导入日志都在项目根目录的 `recording-workspace/`。它已经被 Git 忽略，不会提交，也不会部署。不要用批量或递归删除；如确实需要手动清理，请先停止并只检查一个明确文件路径。

11. 停止服务器

   回到运行启动命令的终端，按 `Control + C`。工作台会关闭本机服务器，已保存的草稿、状态、备份和日志会保留。下次重新启动会继续读取它们。

12. 明确“导入”不是“部署”

   导入只修改你本机项目中的课程音频文件；不会推送 GitHub、不会发布 Vercel、不会同步国内版、也不会让任何公开网站自动更新。任何部署都必须另行确认。

13. 审听全部现有目标

   共有 527 个当前目标。新工作区里 525 个是“待审听”；`alphabet:zhe` 和 `vocab:korushkunche` 一开始就是“需要重录”。必须逐条试听，并明确标记为 `approved-current` 或 `needs-rerecord`。只要还存在任一“待审听”或“需要重录”，后续课程扩充计划仍然不能开始。

14. 后续课程扩充如何进入工作台

   以后确认新增课程内容后，它们会以新的“待审听”目标加入目录，不会因为已有课程通过审听就被自动批准。请按同样的录制、对比、批准、预览和确认流程处理。

## 重要提醒

- 录制新 take、批准新 take、批准现有音频和导入课程是四个独立动作。
- 请在本机地址 `127.0.0.1` 上使用本工具；它不是公共后台。
- 工作台不会替负责人审听或批准 527 条录音。完成真实审听与补录后，再决定是否进入后续课程扩充。
