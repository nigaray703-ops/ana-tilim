# Ana Tilim 中英文学习模式设计

日期：2026-08-09  
状态：用户已确认
适用范围：海外版 `prototype/`（Vercel 部署）

## 1. 目标

为 Ana Tilim 海外版增加中文和英文两种学习语言，让学习者能够用中文或英文学习维吾尔语。

最终体验必须满足：

- 第一次进入时，根据手机或浏览器语言自动选择中文或英文。
- 中文系统默认使用中文；英文及其他语言系统默认使用英文。
- 页面始终提供清晰的“中文 / EN”手动切换入口。
- 用户手动选择后，后续访问优先使用该选择，不再被系统语言覆盖。
- 英文模式不只翻译菜单，还要覆盖课程说明、练习提示、反馈、字母说明、词义和句子释义。
- 维吾尔文、真人录音和 ULY 拉丁转写保持不变。
- 核心学习内容不依赖在线翻译接口或第三方翻译组件。

## 2. 明确不包含的内容

本阶段不包括：

- 英文和中文以外的第三种语言。
- Google Translate 小组件或运行时机器翻译。
- 对现有课程顺序、进度算法、音频内容或 Google 登录流程的重做。
- 中国静态镜像构建的改造；该版本继续保持独立。
- 将维吾尔文界面改为完整 RTL 布局。维吾尔文学习内容继续按现有方式单独使用 RTL 展示。

## 3. 方案选择

采用“系统语言检测 + 手动切换”的组合方案。

与只提供按钮相比，该方案能让首次访问更自然；与只跟随系统相比，它允许用户随时切换学习语言。所有正式译文都随网站打包，不调用境外翻译服务，也不会因翻译服务不可用而阻止核心学习功能。

## 4. 用户体验

### 4.1 首次进入

应用在第一次渲染前读取语言设置：

1. 如果本地进度中已有用户明确选择的语言，直接使用该语言。
2. 如果没有明确选择，则读取 `navigator.languages` 的第一项，缺失时再读取 `navigator.language`。
3. 首选语言代码以 `zh` 开头时选择中文；其他语言统一选择英文。
4. 如果浏览器语言不可读取或值无效，海外版默认使用英文。

这项判断必须在主界面首次渲染前完成，避免页面先显示中文再跳成英文。

### 4.2 手动切换

- 桌面端在全局页头提供紧凑的“中文 / EN”语言选择控件。
- 手机端使用同一控件的紧凑样式，不能挤压主标题或导航按钮。
- “我的 / Profile”设置页同时提供完整的语言设置项，显示“中文”和“English”的本名，不使用国旗代表语言。
- 切换后当前页面立即重新渲染，不丢失正在学习的单元、题目位置或未提交答案。
- 控件必须有可读的辅助技术标签和清楚的选中状态。

### 4.3 语言选择的保存与同步

- 游客模式把语言作为现有学习偏好的一部分保存到本地。
- 现有本地进度、游客注册前备份和云端快照继续包含学习偏好，因此语言选择也会随备份迁移；本阶段不新增独立的文件导出或导入界面。
- Google 用户把语言偏好纳入现有云同步数据；登录后，以现有“较新偏好时间戳”规则决定本地或云端值。
- 如果用户从未手动选择语言，系统检测结果只作为该设备的默认值，不需要立刻写入云端。

## 5. 本地化架构

本地化分成两个边界清晰的部分。

### 5.1 界面文案目录

新增独立的本地化模块，提供：

- 当前语言解析与规范化。
- `t(key, params)` 形式的界面文案读取。
- 简单变量插值，例如完成数量、单元名称和学习天数。
- 英文兜底和开发环境缺失键提示。

中文和英文界面词典使用相同的稳定键，覆盖导航、首页、登录、设置、课程、练习、结果、提示、错误、备份和恢复等文案。业务代码不再直接依赖要展示给用户的中文句子。

### 5.2 课程内容目录

课程内容继续保留维吾尔文字段、ULY 转写、音频路径和稳定 ID。中文原文保持不变，英文内容通过独立的本地课程翻译目录按稳定 ID 对应，避免复制音频、字形和课程结构。

英文目录需要覆盖：

- 32 个字母的类型、点位提示、四种字形名称、连接规则、发音提示、书写提示和例句说明。
- 字母组合与拼读课程的标题、目标、说明和练习文本。
- 词汇主题的标题、学习目标、词义和补充说明。
- 键盘、听力、听写、手写、点位辨认等练习的题目与反馈。
- 阅读内容的标题、人物或背景介绍、句子释义和教学说明。

缺少稳定 ID 的可翻译课程项必须先补充稳定 ID。翻译通过 ID 关联，不能依赖数组位置，以免以后调整课程顺序导致译文错配。

## 6. 渲染与状态流

应用启动流程如下：

1. 载入本地进度和偏好。
2. 解析用户明确选择或系统默认语言。
3. 设置应用当前语言，并更新 `<html lang>`。
4. 载入对应界面词典和课程内容。
5. 渲染当前页面。

手动切换时只更新语言偏好和界面，不重置学习状态。现有 `showLatin` 设置继续独立工作：用户可以在中文或英文界面中分别选择是否显示 ULY，但切换界面语言不能自动改变该设置。

中文和英文界面均为 LTR。维吾尔文字母、单词和句子继续在各自的内容元素中使用 RTL，不把整个英文或中文页面改成 RTL。

## 7. 异常和兜底规则

- 已保存的语言值不是 `zh` 或 `en` 时，忽略该值并重新执行系统语言检测。
- 某个界面翻译键缺失时，使用英文兜底，不向用户显示内部键名。
- 正式构建前的完整性测试必须拦截缺失英文课程译文，避免英文模式悄悄混入中文课程说明。
- 翻译加载失败不能阻止网站启动；应用使用随包英文兜底内容。
- Google 登录或 Supabase 云同步失败时，语言切换和游客学习仍然正常工作。

## 8. 测试与验收

### 8.1 自动化测试

- `zh-CN`、`zh-TW` 等系统语言首次进入为中文。
- `en-US`、`en-GB` 及其他非中文系统语言首次进入为英文。
- 手动切换后刷新页面仍保持选择。
- 无效保存值会安全回退，不显示空白页面或内部翻译键。
- 中文和英文词典键集合一致。
- 所有可见课程项都有完整英文映射，且映射使用稳定 ID。
- 切换语言不会改变课程进度、当前练习位置、答案状态和 `showLatin` 设置。
- 本地保存、游客备份恢复和云同步能够保留明确选择的语言。
- 游客模式和 Google 登录模式的现有测试继续通过。

### 8.2 页面验收

至少检查以下页面的中文和英文模式：

- 首页、导航、个人设置和登录区域。
- 32 个字母总览和字母详情。
- 所有字母单元及其完成页面。
- 点位辨认、手写板、键盘练习、听力、听写和跟读。
- 词汇、字母组合和阅读课程。
- 本地进度、数据备份和恢复。

### 8.3 设备验收

- 桌面端检查页头语言控件、长英文文案换行和按钮宽度。
- 手机端检查语言控件不遮挡标题，英文长词不溢出，文字缩放后仍清楚可读。
- 使用 Vercel 预览部署完成最终浏览器验证，再合并到海外版生产部署。

## 9. 成功标准

满足以下条件才视为完成：

- 中文用户可以完整使用现有中文学习体验。
- 英文用户可以从首页进入并完成核心课程，全程获得英文说明、释义和反馈。
- 首次系统检测、手动切换、刷新保持、备份恢复和登录同步均符合本设计。
- 语言功能不依赖运行时翻译服务，不破坏游客学习、Google 登录、音频和现有进度。
- 手机端和桌面端没有因英文文案变长产生遮挡、溢出或不可读问题。
