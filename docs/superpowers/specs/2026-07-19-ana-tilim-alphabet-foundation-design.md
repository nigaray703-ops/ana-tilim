# Ana Tilim 字母基础阶段课程设计

## 目标

Ana Tilim 的第一阶段先做“字母基础”，不急着进入家庭称呼、场景词汇或句子。

学习顺序调整为：

> 字母概念 → 单个字母 → 字母形态 → 书写 → 键盘 → 连接规则 → 再进入单词主题

这样用户先理解维吾尔文的底层规则，再进入家庭称呼、基础词汇和句子，难度会一点一点上去。

## 核心决定

完整产品会覆盖维吾尔文 32 个字母。

第一批 MVP-0 不一次性做完 32 个字母，而是先做：

- 完整字母目录，让用户知道后面都会学
- 字母入门说明，讲清楚从右到左、字母变形、点位、元音承载符
- 第一组 3 个字母，先走通完整学习体验

第一组建议：

1. `ئا`
2. `ب`
3. `ل`

原因：

- `ئا` 适合讲“元音开头为什么有 ئ”
- `ب` 点位清楚，适合做第一个辅音和书写练习
- `ل` 形状简单，能和 `ب`、`ئا` 组合出后续示例词 `بالا`

## 标准语原则

课程主线统一按标准维吾尔语设计。

南疆、北疆、家庭口语和地区说法可以保留，但不作为第一版主答案直接混在一起教。后续进入家庭称呼时，词条需要区分：

- 标准维吾尔语主词
- 中文含义
- 拉丁转写
- 地区/口语变体
- 哪些变体可以作为识别题或输入题的可接受答案
- 哪些变体只作为备注展示
- 审校状态

例如“妈妈”不应只假设为 `ana`，也可能出现 `apa`；“爸爸”不应只假设为 `ata`，也可能出现 `dada`。正式课程要先确定标准主词，再把其他说法放入变体字段。

字母阶段可以使用词作为示例，但不要在字母阶段提前把家庭称呼定死。家庭 / 基础称呼会在字母阶段结束后单独设计。

## 学习分组

字母目录可以显示官方/常见字母表顺序，但真正学习时按难度分组。

### 0. 入门概念

先讲：

- 维吾尔文从右到左
- 字母会根据位置变形
- 同一个字母有独立、词首、词中、词尾形式
- 点的位置很重要
- 元音开头通常需要 `ئ`
- 有些字母后面不会继续连接

这一节不要求记住很多字母，只让用户知道“为什么会变形”。

### 1. 第一组：最小闭环

字母：

- `ئا`
- `ب`
- `ل`

能力目标：

- 认识第一个元音和两个简单辅音
- 能看懂 `ب`、`ل` 的基本形态
- 能描摹 `ب`
- 能在键盘里找到 `ب`、`ا`、`ل`
- 为后续示例词 `بالا` 做准备

### 2. 第二组：高频简单辅音

字母：

- `م`
- `ن`
- `ت`
- `س`

能力目标：

- 继续练习点位
- 熟悉常见连接
- 开始做简单辨认题

### 3. 第三组：点位和形近字

字母：

- `پ`
- `ج`
- `چ`
- `ش`

能力目标：

- 重点区分点的数量和位置
- 练习看图识别和听音选择

### 4. 第四组：断开连接字母

字母：

- `د`
- `ر`
- `ز`
- `ژ`

能力目标：

- 理解哪些字母后面会断开
- 练习单词中“为什么这里没有连上”

### 5. 第五组：较难发音

字母：

- `خ`
- `غ`
- `ق`
- `ك`
- `گ`
- `ڭ`

能力目标：

- 区分较难发音
- 给中文用户提供谨慎的发音提示
- 避免第一版做过度精准的发音评分

### 6. 第六组：剩余常用辅音

字母：

- `ف`
- `ھ`
- `ۋ`
- `ي`

能力目标：

- 完成主要辅音认识
- 强化键盘输入和听音选择

### 7. 元音专项

字母：

- `ئە`
- `ئې`
- `ئى`
- `ئو`
- `ئۇ`
- `ئۆ`
- `ئۈ`

能力目标：

- 系统认识元音
- 理解 `ئ` 在元音开头的作用
- 对比普通元音和圆唇元音

## 每个字母的数据字段

每个字母最终都要整理成同样结构，方便以后接入网页或 App：

- `id`：唯一编号
- `letter`：主字母
- `latin`：拉丁转写
- `type`：元音 / 辅音 / 元音承载相关
- `isolated`：独立形式
- `initial`：词首形式
- `medial`：词中形式
- `final`：词尾形式
- `connectsAfter`：后面是否继续连接
- `soundHintZh`：中文发音提示
- `writingHintZh`：书写提示
- `commonConfusions`：容易混淆的字母
- `keyboardHint`：键盘位置提示
- `exampleWords`：示例词
- `audioNeeded`：是否需要真人音频
- `reviewStatus`：是否已审校

## MVP-0 课程文件

下一步先创建两类课程资料：

1. 字母路线说明

   文件建议：`课程/字母/00-字母基础路线.md`

   内容包括完整 32 字母目录、学习分组、每组目标、难度递进说明。

2. 第一组字母资料表

   文件建议：`课程/字母/01-第一组-ئا-ب-ل.md`

   内容包括 `ئا`、`ب`、`ل` 的形态、发音提示、书写提示、连接说明、键盘练习和后续示例词准备。

后续再补一个机器可读数据文件：

`课程/字母/alphabet-data.json`

第一版可以先写 Markdown，方便人检查；等内容稳定后再转成 JSON。

## 审校要求

这部分内容涉及语言准确性，需要特别谨慎。

第一版允许先写“教学草稿”，但以下内容必须经过你或维吾尔语母语者审校后才能作为正式课程：

- 发音提示
- 示例词
- 中文翻译
- 字母连接规则
- 书写方向
- 键盘位置说明
