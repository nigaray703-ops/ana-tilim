# 逐词词素参考与真实维吾尔语键盘设计规格

日期：2026-08-08
状态：等待用户书面复核
适用版本：Ana Tilim（国外版）与 Uyghur Tili（国内版）

## 1. 版本同步规则

- 除非用户明确点名“只改国内版”或“只改国外版”，产品功能和界面修改默认同时应用到两个版本。
- 共用实现先在 Ana Tilim 的 `prototype/` 中完成并验证，再同步到 Uyghur Tili 的 `site/`，最后重新生成 `dist-cn/`。
- 版本差异继续由独立配置控制：国外版保留可选登录与云端同步；国内版不显示登录、注册和云端同步入口，只使用本地进度。

## 2. 逐词与词素参考

### 2.1 展示位置与方向

- 采用用户确认的第三种样式：参考区直接放在句子或词汇内容下方，不打开新页面或弹窗。
- 内容整体居中，词卡严格按照维吾尔语原文从右向左排列。
- 标题旁显示明确的向左箭头，并写出“从右向左理解”，帮助初学者确定阅读起点。
- 每个基础词卡按三行显示：维吾尔文、拉丁转写、中文参考词义。
- 保留提示：维语与汉语语序不同，词义用于帮助理解结构，并非逐字位置完全对应。

### 2.2 词素拆解

- 只有数据中明确标记为可拆解的词才显示词素行，不自动猜测词根或后缀。
- 拆解顺序与原词一致，视觉顺序从右向左。
- 例如 `بارمۇ` 的右侧先显示词根 `بار`（有、存在），左侧再显示后缀 `مۇ`（吗，疑问标记）；两者之间使用向左箭头表达理解顺序。
- 类似 `ياخشىمۇسىز` 的复合结构继续保留词素拆解。
- 词素行放在所属词卡内部，不能脱离原词或改变原句词序。

### 2.3 不显示的情况

- 单个且不可拆解的词，例如仅有 `رەھمەت` 的句子，不显示重复的“逐词与词素参考”区域，因为原卡已经提供转写和中文意思。
- 词汇列表中的普通单词也不重复显示参考区；只有存在明确词素拆解数据时，才在该词条下方显示拆解。
- 没有可靠词义或词素数据时隐藏该项，不显示“待补充”之类占位文字。

### 2.4 可访问性与响应式

- 维吾尔文使用 `dir="rtl"`，拉丁转写和中文使用 `dir="ltr"`，避免浏览器双向排版打乱内容。
- 箭头同时提供可读文字说明，不能只依赖颜色表达方向。
- 桌面端保持横向词卡，窄屏允许换行，但每一行仍从右侧开始并保持原文顺序。

## 3. 真实维吾尔语键盘

### 3.1 标准与键位

键盘采用 Microsoft Windows 现行 Uyghur 布局（KLID `00010480`）的普通层和维吾尔语字母所需 Shift 层。字母练习按物理 QWERTY 键盘三行显示并保留错位，不再使用五列字母方格。

| 物理键位 | 网页键帽（从左到右） |
| --- | --- |
| Q–P | `چ` `ۋ` `ې` `ر` `ت` `ي` `ۇ` `ڭ` `و` `پ` |
| A–L | `ھ` `س` `د` `ا` `ە` `ى` `ق` `ك` `ل` |
| Z–/ | `ز` `ش` `غ` `ۈ` `ب` `ن` `م` `،` `.` `ئ` |

Shift 层中属于课程字母的映射为：`Shift+D → ژ`、`Shift+F → ف`、`Shift+G → گ`、`Shift+H → خ`、`Shift+J → ج`、`Shift+K → ۆ`。其余 Shift 标点按官方布局显示，但不作为字母课程目标。

实现来源：

- Microsoft Learn《Uyghur Keyboard》，标识该布局为 KLID `00010480`。
- MicrosoftDocs 官方键盘布局文件 `kbdughr1.html`，提供 Q、W、E…到每个维吾尔文字母的实际映射。

### 3.2 练习行为

- 每个键帽主要显示普通层维吾尔字母，角落显示对应物理键（Q、W、E 等）；存在 Shift 字母的键帽同时显示较小的 Shift 层字母。
- 网页键盘提供可操作的 Shift 键。课程目标需要 Shift 时，先高亮 Shift，再高亮目标键；点击一次字母后自动释放网页 Shift 状态。
- 当前应按的键使用现有金色引导样式；已完成的键使用现有青绿色完成样式。
- 点击网页键帽继续可用，同时监听实体键盘的 `KeyboardEvent.code` 与 `shiftKey`，映射到同一个维吾尔字母。
- `ئا`、`ئە` 等带前置 `ئ` 的课程字母按真实键盘拆为两个按键步骤，不能继续用一个虚拟快捷键一次填入整个字母。
- 保留删除和清空；删除键放在键盘右上或工具行，空格键仅在词语/组合输入需要空格时启用。
- 字母、组合、词汇和独立键盘复习统一复用同一份布局数据，避免不同课程出现不同键位。
- 课程目标为字母时，非目标键仍显示，模拟真实键盘；错误输入继续按现有本地错题逻辑记录。

### 3.3 响应式

- 桌面端显示完整三行键盘和真实错位。
- 窄屏保持每行键位顺序，不改成字母表顺序；允许整体横向压缩或在键盘容器内部横向滚动。
- 键帽保持足够的点击面积，维吾尔字母不能被裁切。

## 4. 数据与实现边界

- 逐词词义和词素拆解继续来自项目本地 `sentence-glossary.js`，不调用在线翻译、AI、Supabase 或外部 API。
- 键盘布局写入项目本地 JavaScript，不加载第三方键盘脚本或 CDN。
- 国内版构建后所有 JavaScript、CSS、字体、图片、音频和配置继续使用相对本地路径。
- 本次不改变课程内容顺序、学习进度格式、真人录音、听力、听写、手写板、导入导出及两版既有配置差异。

## 5. 课程完成后的连续学习

- “继续学习本单元下一课程”不是第一组字母专用，而是所有章节共用的连续学习规则。
- 只要当前章节中还有下一课程，完成页就在“进入下一单元/复习”和“回到首页/学习路径”之前显示主按钮“继续学习本单元下一课程”。
- 点击后直接打开同一章节的下一课程，并从该课程的第一个学习项目开始。
- 当前课程是本章节最后一课时，不显示这个按钮，避免跳到不存在的课程。
- 字母、字母组合、基础词汇以及存在课程完成页的其他章节统一复用同一个“查找同单元下一课程”逻辑，不能为某一章硬编码。
- 原有“进入下一单元”“复习本组”“回到首页/学习路径”入口继续保留。

## 6. 本地头像与昵称

- 本地模式复用国外版现有的头像选择器与昵称输入样式，不另做一套不同界面。
- 国内版以及国外版未登录状态都允许修改本地昵称与头像；国外版登录后继续使用原有云端个人资料。
- 昵称去除首尾空格后必须为 1–40 个字符，保存后立即更新“我的”页面。
- 本地头像支持 JPEG、PNG、WebP 和 GIF 源文件，选择后在浏览器内缩放为适合头像显示的小尺寸图片，再写入本地学习记录，不能上传到外部服务。
- 未选择头像时显示品牌首字母占位；更换头像时覆盖旧头像。
- 本地昵称和头像随学习记录一起导出与导入，换浏览器时可以通过备份恢复。
- “清除学习记录”只清除课程进度、错题和最近位置，不清除用户主动设置的本地头像与昵称。

## 7. 验收标准

1. 同一句多词维吾尔语按原文从右向左显示，方向提示清楚可见。
2. `بارمۇ` 的词根 `بار` 位于右侧，后缀 `مۇ` 位于左侧，拆解箭头向左。
3. `رەھمەت` 这类单个不可拆词不出现重复参考区。
4. 普通词汇不重复解释；可拆词仍显示词素行。
5. 虚拟键盘与 KLID `00010480` 的三行基础字母映射一致，并具有物理键盘错位。
6. 鼠标/触摸点击和实体 QWERTY 键盘输入都能完成练习。
7. 两版共享功能表现一致；国内版仍无登录、注册、云同步和外部核心依赖。
8. Ana Tilim 全量项目检查通过，Uyghur Tili 国内静态测试通过。
9. 重新生成 `dist-cn/`，最外层存在 `index.html`，本地浏览器完成桌面和窄屏视觉检查。
10. 上传新 `dist-cn/` 到现有 CloudBase 环境后，再核对线上首页和核心学习路径。
11. 每个存在下一课程的完成页显示“继续学习本单元下一课程”，点击后进入同章节下一课；章节最后一课不显示该按钮。
12. 本地模式可以更换昵称与头像，刷新后仍保留，并能通过学习记录导出/导入恢复；全程不访问外部服务。
