# 昵称原地编辑与词素行内展示设计

## 目标

同时更新海外版 Ana Tilim 与国内版 Uyghur Tili：

1. 将昵称编辑入口移动到个人页顶部昵称右侧。
2. 保留用户已经保存的本地昵称、头像和学习记录，不重置或迁移覆盖现有数据。
3. 删除设置区域中重复的昵称输入框和保存按钮。
4. 在词汇列表中，将有可靠显式拆分数据的词直接在对应词条下展示词素解释。
5. 删除词汇卡片最下方重复的整块“逐词与词素参考”。

## 个人页交互

- 昵称标题与一个小铅笔按钮位于同一行。
- 铅笔按钮提供明确的 `aria-label="修改昵称"`，不只依赖图形表达用途。
- 点击铅笔后，标题位置原地切换为昵称输入框，并自动填入当前昵称。
- 编辑状态提供“保存”和“取消”按钮。
- 保存继续使用现有昵称验证规则：去除首尾空格、不能为空、最多 40 个字符。
- 保存继续写入现有本地或云端资料字段；不创建新的存储键，因此现有昵称、头像和学习记录保持不变。
- 取消恢复原昵称，不写入存储。
- 设置区域仍保留账号状态、导入、导出和清除学习记录，但不再渲染昵称编辑区。

## 词汇与词素展示

- 词素拆解直接位于对应维吾尔语词条下方，而不是统一显示在词汇卡片底部。
- 排列遵循维吾尔语原文顺序并使用从右向左的视觉方向；词素之间保留向左箭头。
- 每个词素显示维吾尔文、拉丁转写和中文含义。
- 仅使用词库中已有的显式 `segments` 数据；不按字符或后缀自动猜测拆分。
- 没有可靠显式拆分数据的单词不显示空白占位，也不显示词素模块。
- 词汇课页面不再调用底部的整句/整词参考卡。阅读和对话课程原有的句子逐词参考暂不改变，因为它承担句子语序解释，不是词汇列表的重复内容。

## 数据与兼容性

- 国内外两版使用相同的昵称编辑状态、保存动作和词素渲染规则。
- 国内版继续只使用本地资料；海外版登录用户仍可沿用云端昵称保存逻辑，游客继续使用本地资料。
- 不改变头像处理、学习进度、本地导入导出或云端同步的数据结构。
- 现有浏览器本地存储内容无需迁移。

## 错误处理

- 空昵称或超长昵称沿用现有中文提示，编辑状态保持打开以便修正。
- 云端保存失败时保留输入值并显示错误；不覆盖原昵称。
- 取消编辑不会触发保存或同步。

## 测试与验收

- 自动测试先证明当前页面缺少铅笔入口、仍包含底部昵称编辑区、词汇页仍包含底部重复参考。
- 修改后验证：
  - 顶部昵称旁存在可访问的铅笔按钮。
  - 点击后显示预填当前昵称的输入框、保存和取消。
  - 本地保存后刷新仍显示新昵称；已经保存的头像保持不变。
  - 取消不改变昵称。
  - 设置区域不再出现“本地昵称/保存昵称”或登录版的重复名称编辑区。
  - 所有带显式词素数据的词在自身词条下展示；无拆分数据的词不展示。
  - 词汇卡片底部不再出现重复的“逐词与词素参考”。
  - 海外版完整检查、国内版静态检查、CloudBase 构建和两版浏览器交互检查均通过。

## 不在本次范围

- 不自动推断或批量创造未经审校的维吾尔语词素数据。
- 不改变阅读/对话句子的逐词语序参考。
- 不改变登录、同步、头像上传、学习进度或音频功能。
