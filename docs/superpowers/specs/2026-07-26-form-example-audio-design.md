# 写法例词音频设计

## 背景

字母课程的“写法例词”当前显示 126 个不重复的维吾尔语例词，但例词卡没有连接音频。现有真人音频库中，32 个例词可以按完整维吾尔语词形精确复用词汇或组合音频，其余 94 个例词没有对应录音。

## 目标

- 让已有真人音频的写法例词可以直接点击播放。
- 把没有真人音频的例词加入录音中心，供用户自行录制。
- 同一个例词即使出现在多个字母页面，也只保留一个录音目标并共用一份音频。
- 保持例词中目标字母的红色高亮和完整阿拉伯连写不变。

## 非目标

- 不把 94 个待录例词加入第三单元正式词汇表。
- 不为同一个词的不同字母位置创建重复录音。
- 不把浏览器中刚录制的临时 Blob 当作已经接入课程的永久音频；课程播放仍以项目内真人音频文件为准。
- 不改变例词、中文释义或字母位置标记。

## 方案

### 唯一例词目录

从 `letterDetails[*].formExamples` 中读取所有非空 `word`，按完整维吾尔语词形去重，形成 126 个唯一例词记录。每条记录保存：

- `value`：完整维吾尔语例词；
- `latin`：数据中第一个可用的拉丁转写，没有转写时显示“未提供转写”；
- `meaning`：第一个可用的中文释义；
- `occurrences`：该词出现的字母 ID 和位置标签，用于审计，不生成重复录音。

录音目标 ID 使用完整词形计算出的稳定短哈希，格式为 `form-example-<hash>`。同一词无论出现在哪个页面都得到相同 ID。测试必须验证 126 个 ID 无碰撞。

### 现有音频解析

按完整维吾尔语词形精确匹配现有可播放音频：

1. 优先复用正式词汇音频；
2. 没有词汇音频时复用组合音频；
3. 不用包含该词的句子音频替代单词音频；
4. 多个页面出现同一词时共用解析结果。

当前基线应得到 32 个已有音频例词和 94 个待录例词。若以后音频库变化，完整音频检查必须同时更新基线。

### 待录例词

录音中心增加独立分类：

- 分类 ID：`form-example`
- 分类名称：`例词`
- 单元：`第一单元`
- 分组：`写法例词`

该分类列出全部 126 个唯一例词：

- 32 个已有音频的词显示在“已录/重录”模式；
- 94 个没有音频的词显示在“待录”模式；
- 该分类中新录或重录的下载文件名始终使用 `voice_form_example_<hash>.webm`，不覆盖被复用的词汇或组合音频文件；
- 后续把录音文件接入项目时，永久文件放入 `prototype/assets/audio/human/form-examples/`，文件名使用 `human_form_example_<hash>.webm`。

用户在录音中心录制并下载文件后，课程例词只有在该文件被加入项目并登记为已连接音频时才变为可播放。

### 学习页交互

- 有音频的例词把完整单词渲染为按钮，点击单词播放真人音频。
- 按钮保留 `.form-example-word-text`、目标范围数据属性和一个完整文本节点，确保红色字母高亮仍按原有范围测量。
- 按钮提供 `aria-label="播放 <例词>"`、键盘焦点样式和轻量的可点击提示，不改变卡片布局。
- 没有音频的例词继续显示为普通静态文字，不显示禁用或无效播放按钮。
- 中文释义保持原位。

## 数据流

1. 字母数据生成唯一例词目录。
2. 应用按词形从词汇音频映射和组合音频映射中解析可复用音频。
3. `renderLetterFormExamples` 把解析结果传给例词渲染函数。
4. 可播放例词复用现有 `play-audio` 事件；静态例词不产生播放动作。
5. 唯一例词目录同时生成 `form-example` 录音分类。
6. 新录音文件以后加入专用目录并登记后，解析结果转为可播放，所有出现位置同时生效。

## 错误与一致性规则

- 例词 ID 必须唯一，哈希碰撞使测试失败。
- 一个词同时匹配词汇和组合音频时只选择词汇音频。
- 音频路径为空或不可播放时按待录处理，不渲染播放按钮。
- 空例词和“无例词”规则卡不创建录音目标。
- 例词按钮不得拆分阿拉伯文本节点，不得破坏红色目标字母高亮。
- 录音中心总数从 439 增加到 565；已有音频从 439 增加到 471；待录增加为 94。

## 测试与验收

自动检查：

- 唯一例词总数为 126，且词形、目标 ID 均无重复。
- 32 个例词解析到现有音频，94 个例词为待录。
- 录音中心包含 `form-example` 分类，并显示正确的已有/待录数量。
- `ئانا`、`قارا` 在字母 `ئا` 页面渲染为可播放例词。
- `ئالما`、`خەلقئارا` 保持静态，并出现在例词待录清单。
- 同一例词出现在多个页面时使用同一音频和同一录音目标。
- 点击已有音频例词触发正确文件路径和播放提示。
- 所有例词仍保留完整文本节点和目标字母高亮属性。
- 完整内容渲染、真人音频检查和空白字符检查继续通过。

浏览器验收流程：

1. 打开字母 `ئا` 学习页。
2. 点击 `ئانا` 和 `قارا`，确认播放对应真人音频。
3. 确认 `ئالما` 和 `خەلقئارا` 没有无效播放动作。
4. 打开“录音”页面并选择“例词”。
5. 确认待录数量为 94，且能选择 `ئالما`、`خەلقئارا` 进行录音。
6. 检查控制台无相关错误，并截图验证桌面布局。
