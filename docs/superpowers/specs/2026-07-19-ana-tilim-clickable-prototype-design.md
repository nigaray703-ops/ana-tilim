# Ana Tilim 可点击网页原型设计

## 目标

做一个手机优先的静态真实网页原型，让项目创作者可以在浏览器里实际点击、浏览、体验 Ana Tilim 的第一条学习路径。

这个原型不是正式产品，也不是完整技术架构。它的任务是帮助确认：

- Ana Tilim 的整体视觉方向是否对味
- 首页和底部导航是否清楚
- 用户能不能顺利走完一次学习闭环
- 字母、书写、词汇、键盘输入这些核心模块放在一起是否自然
- 后续正式开发前，哪些页面和交互需要调整

## 原型范围

原型放在 `prototype/` 目录内，使用静态 `HTML + CSS + JavaScript` 实现。

包含页面：

- 启动 / 欢迎页
- 首页
- 学习路径页
- 字母学习页
- 字母书写页
- 图片词汇练习页
- 听音选择页
- 维吾尔语键盘输入页
- 课程完成页
- 我的页面

暂不包含：

- 注册登录
- 云端同步
- 真实数据库
- 真实音频文件上传
- 精准发音评分
- 精准手写识别
- 真实 PWA 安装配置
- 管理后台

## 原型学习流程

主流程：

1. 用户进入欢迎页，看到 Ana Tilim 品牌和“开始学习”按钮。
2. 进入首页，看到今日学习状态、继续学习按钮和几个快捷入口。
3. 点击继续学习，进入 MVP-0 学习路径。
4. 学习第一个字母，查看独立、词首、词中、词尾形式。
5. 进入书写页，看到浅色参考字和模拟描摹画布。
6. 进入图片词汇练习，选择正确答案。
7. 进入听音选择，点击播放按钮并选择答案。
8. 进入键盘输入页，看到 RTL 输入框和维吾尔语键盘。
9. 完成课程，看到学习成果和继续复习入口。

辅助导航：

- 底部导航固定为：首页、学习、书写、词库、我的。
- 原型中的按钮需要能点击并切换到对应页面或弹出轻提示。
- 用户不需要真的登录或输入大量内容。

## 示例内容

原型使用少量假数据，重点展示产品体验，不追求课程完整。

建议内容：

- 字母：ب
- 字母形态：ب、بـ、ـبـ、ـب
- 示例词：بالا
- 中文含义：孩子
- 拉丁转写：bala
- 示例主题：家庭 / 基础称呼

这些内容可以在后续课程整理阶段替换。原型代码中的数据应集中放在 JavaScript 常量里，避免散落在多个地方。

## 视觉方向

使用项目已有 Logo 作为品牌参考，整体风格：

- 现代
- 柔和
- 手机优先
- 轻游戏化
- 文化元素克制

颜色：

- 深靛蓝作为主色
- 湖蓝作为辅助色
- 暖白作为背景
- 柔和金色作为小面积强调
- 青绿色用于正确反馈
- 低饱和珊瑚红用于错误反馈

界面原则：

- 不做复杂民族纹样堆叠
- 不做儿童化卡通风格
- 不做后台仪表盘风格
- 维吾尔文使用大字号，保持清晰
- 页面适合手机查看，桌面端居中显示手机宽度

## 交互设计

点击规则：

- 主按钮推动用户进入下一步
- 底部导航可切换主页面
- 练习题选择后显示正确 / 错误反馈
- 书写页提供清除、撤销、显示参考等按钮，但可以先做视觉和简单状态切换
- 键盘页点击虚拟键盘按钮时，把字符填入 RTL 输入框
- 完成页展示本次学习成果

状态规则：

- 当前页面状态使用一个简单的 JavaScript 变量保存
- 练习选择、输入框内容、收藏状态可以用前端状态模拟
- 不要求刷新后保存

错误和空状态：

- 如果用户点击未实现的功能，显示“这个功能会在正式版加入”的轻提示
- 输入错误时显示温和反馈，不打断流程
- 页面不能出现空白死路，所有页面至少有返回首页或继续按钮

## 文件结构

建议结构：

```text
prototype/
  index.html
  styles.css
  app.js
  assets/
    logo.png
```

`assets/logo.png` 使用从原始 Word 文档中提取的 Logo 图片副本。

## 验收标准

完成后需要验证：

- 可以直接打开 `prototype/index.html`
- 首页、学习、书写、词库、我的底部导航可点击
- 从欢迎页到课程完成页可以完整走通
- 维吾尔文从右到左显示正常
- 手机宽度下没有文字重叠或按钮溢出
- 桌面浏览器中页面居中，不铺满成杂乱的大屏
- Logo 能正常显示
- 虚拟键盘能把字符输入到 RTL 输入框
- 练习题点击后能显示反馈

## 后续扩展

如果这个原型方向确认，再进入下一步：

1. 把原型拆成正式 Next.js 页面和组件。
2. 整理 MVP-0 的真实课程数据。
3. 替换真实音频、图片和练习题。
4. 加入本地进度保存。
5. 再逐步做 PWA、部署和更多课程。
