# 真实维吾尔语键盘与句子词素说明设计

日期：2026-08-09

## 目标与范围

本轮同时更新 Ana Tilim 海外版与 Uyghur Tili 国内版。两版继续共享学习逻辑，仅保留各自已有的版本配置、品牌与部署方式。

本轮包含两个改动：

1. 将键盘练习中的屏幕键盘调整为用户提供的真实手机维吾尔语键盘结构。
2. 在句子、对话、故事和谚语的“逐词与词素参考”中，为可以可靠分析的词补充词干、后缀和连接变化。

本轮不改变网站字体，不在普通词汇课程中恢复任何词素拆解，也不加入登录或云端功能。

## 键盘设计

### 字母与键位

继续使用现有标准维吾尔语 QWERTY 映射，因为它与用户提供的手机键盘截图一致：

- 第一排：`چ ۋ ې ر ت ي ۇ ڭ و پ`
- 第二排：`ھ س د ا ە ى ق ك ل`
- 第三排：`ز ش غ ئۈ ب ن م`
- Shift 字母：`ژ ف گ خ ج ۆ لا`
- 独立 Hamza：`ئ`

键位输出逻辑、物理键盘输入和练习判定继续共用 `uyghur-keyboard.js`，避免屏幕键盘与实体键盘产生两套规则。

### 手机键盘外观

屏幕键盘改为用户截图中的手机结构：

- 第三排左侧放 Shift 图标，右侧放退格图标。
- 为保证课程中的 `ئ` 和 `ئا` 等目标可以直接找到，第三排在退格键前保留一个清楚可见的 `ئ` 键；这是相对手机截图唯一有意保留的教学键。
- 底部放 `123`、表情图标、宽空格键 `بوشلۇق` 和确认键 `يوللا`。
- 空格、Shift、退格和确认键具有真实功能。
- `123` 与表情键仅作为真实键盘的视觉上下文，使用禁用状态，不增加与当前学习目标无关的数字或表情输入层。
- 不再在每个字母键上显示醒目的拉丁键帽；需要的实体键提示以较弱的小标签保留，确保键盘练习仍能教会 QWERTY 对应位置。
- 桌面端保持手机键盘比例但限制最大宽度并居中；窄屏自适应，不出现水平滚动。

### 教学状态

- 下一步应点击的键继续高亮。
- 需要 Shift 时先高亮 Shift，再高亮目标字母。
- 输入正确、错误、删除和清空行为维持现有逻辑。
- 确认键在当前目标完成后等同于现有“完成课程”或进入下一步的行为；未完成时不提前结束。

## 词素说明设计

### 显示范围

词素说明只出现在句子类内容：基础句型、对话、小故事和谚语。

普通词汇课程继续保持简洁，不显示：

- 单词下方词素拆解；
- 底部“逐词与词素参考”；
- “当前词汇 / x/x”状态条。

### 数据结构

每个可拆词允许包含：

- `surface`：词中实际出现的部分；
- `base`：词典形式或词干；
- `latin`：本地生成的 ULY 转写；
- `meaning`：中文功能说明；
- `change`：可选的连接、元音和谐或字母变化说明；
- `formation`：完整构词公式。

示例：

`كىتاب + ـىڭىز → كىتابىڭىز`

- `كىتاب / kitab`：书；
- `ـىڭىز / -ingiz`：您的，第二人称礼貌或复数物主后缀；
- 连接说明：词干末尾不变，接物主后缀 `ـىڭىز`。

页面继续按照维吾尔语原文从右向左排列，并用向左箭头连接。构词变化说明放在该词内部，不放到整页最下方。

### 准确度原则

- 只人工录入能够可靠确认的分析。
- 不依靠前端自动猜测后缀，不为了覆盖率强行拆词。
- 不确定、习惯化或无法清楚解释的词继续显示整词意思。
- 同一个词在不同语境中意义不同的，允许按句子覆盖通用解释。
- 连接变化必须显示“原形 + 后缀 → 实际词形”，不能只显示切开的片段。

## 测试与验收

### 键盘

- 正常层、Shift 层和实体键映射测试全部通过。
- `ئ`、`ۈ`、`ۆ`、`ژ`、`لا` 等容易遗漏的输出有单独测试。
- 空格、退格、Shift、高亮步骤和确认键均可使用。
- 桌面与手机宽度下无横向溢出。

### 词素

- 164 个现有句子继续具有完整逐词解释，不出现“词义待补充”。
- 每条人工拆解必须包含中文意义和 ULY 转写。
- 含连接变化的词必须提供构词公式及变化说明。
- `كىتابىڭىز`、`ياخشىمۇسىز`、`بارمۇ` 等代表性词有回归测试。
- 词汇课程必须持续验证没有词素拆解和底部参考框。

### 两版与部署

- 海外版与国内版的键盘、词素数据和样式保持一致。
- 国内版重新生成 `dist-cn`，静态资源继续使用相对路径。
- 本地测试通过后再部署到原 CloudBase 地址，并核对控制台错误、图标及抽查音频。

## 不包含的内容

- 不修改字体。
- 不增加数字键盘或表情选择器。
- 不在普通词汇课程恢复拆解。
- 不自动生成未经人工确认的维吾尔语语法分析。
- 不修改现有用户的本地进度、昵称或头像。
