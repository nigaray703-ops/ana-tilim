# Ana Tilim 全部单元学习体验完善设计

## 目标

把现有四个单元变成更适合零基础学习者使用的连续学习体验。

本次不新增大量课程内容，不扩展第五单元，不把待审校词条变成正式答案。重点是让学习路径更清楚、练习反馈更直接、每个单元都有可以完成的小闭环。

## 范围

包含：

- 首页显示清楚的下一步学习建议。
- 学习路径页展示每个单元的步骤和完成感。
- 第一单元到第四单元的详情页都有更明确的学习顺序。
- 单元内页面增加“上一个 / 下一个”式的前进体验。
- 每个单元结束页提供复习入口和下一单元入口。
- 练习答错时给出温和提示，并引导回到对应学习内容。
- 听音按钮继续支持 AI 临时音频路径，但没有文件时只提示，不假装已经有真实音频。

不包含：

- 新增第五单元。
- 新增大量新词。
- 登录、云同步、数据库。
- 真实发音评分或手写识别。
- 生成 AI 音频文件。
- 把 `待母语者审校` 内容改成最终标准内容。

## 学习体验结构

### 首页

首页从“项目概览”调整成“今天该做什么”的感觉。

首页需要显示：

- 当前推荐：继续第一单元复习或进入当前选择的单元。
- 四个单元的简短状态。
- 快捷入口：继续学习、单元复习、审校看板。
- 音频状态提醒：AI 音频只是临时测试，真实音频仍待录制。

### 学习路径页

学习路径页保留四个单元，但每个单元卡片更像学习任务，而不是普通目录。

每个单元卡片显示：

- 单元名。
- 学习目标。
- 三到四个步骤。
- 状态：已完成 / 进行中 / 待审校。
- 一个明确按钮：进入单元。

### 单元详情页

单元详情页需要告诉用户：

- 这一单元先学什么。
- 学完后做什么练习。
- 当前单元完成后去哪里。

每个单元都使用相同结构：

1. 单元目标。
2. 本单元小步骤。
3. 分组列表。
4. 进入当前学习。
5. 单元复习 / 下一单元入口。

## 四个单元的具体完善

### 第一单元：认识字母

保持已有相似字母分组。

增强点：

- 每个字母页增加“上一个字母 / 下一个字母”。
- 字母页显示当前分组进度，例如 `1 / 4`。
- 听音按钮显示 `AI 临时音频` 标记；没有 mp3 时提示音频未生成。
- 练习页答错后提示回到当前字母组复习。
- 第一单元完成页提供“复习本组”和“进入第二单元”。

### 第二单元：组合与词组入门

保持两字母、三字母、基础称呼预览的结构。

增强点：

- 组合详情页增加“上一个组合 / 下一个组合”。
- 组合页面突出“从右往左拆分”。
- 基础称呼继续标记为预览和待审校，不设唯一答案。
- 第二单元完成页提供“复习组合”和“进入第三单元”。

### 第三单元：基础词组与主题词

保持问候、人称、家庭、数字四个主题。

增强点：

- 词条页增加主题内前后切换。
- 词条页显示审校状态和是否可考核。
- 识别题和输入题错误时提示“现在只练词形，不考最终中文含义”。
- 家庭称呼继续作为重点审校项，不把 `ئانا / ئاپا` 或 `ئاتا / دادا` 强行设成唯一答案。
- 第三单元完成页提供“复习词形”和“进入第四单元”。

### 第四单元：听说与书写强化

第四单元不新增词，只复用前三个单元。

增强点：

- 训练组页面明确显示当前训练类型：听音、跟读、书写、复习。
- 完成页展示本轮完成内容。
- 听音和跟读继续标记真实音频待录制或 AI 临时音频。
- 完成后提供“再练一轮”和“回到学习路径”。

## 交互规则

- 所有返回按钮继续使用符号，不使用文字。
- 主要按钮文字必须说明下一步动作。
- 页内导航使用短标签，避免长中文挤压。
- 错误反馈要温和，不说用户“错了很多”。
- 中文说明可以换行或缩小，不能挤出卡片。
- 不新增复杂动画，优先保证手机宽度可读。

## 数据与状态

继续使用 `prototype/app.js` 的本地状态。

需要增加的状态：

- 当前单元推荐入口。
- 当前项目在组内的位置。
- 练习完成后的下一步目标。

不需要保存到本地存储。刷新后回到默认状态可以接受。

## 文件影响

预计修改：

- `tests/unit-learning-experience.test.mjs`
- `docs/superpowers/plans/2026-07-19-ana-tilim-unit-learning-experience-plan.md`

- 课程 Markdown 的语言内容，除非只是补充体验说明。
- 音频 mp3 文件。

## 验收标准

- 打开原型后，首页能看出下一步该做什么。
- 四个单元详情页都有清楚的学习步骤。
- 第一单元字母页可以前后切换字母。
- 第二单元组合页可以前后切换组合。
- 第三单元词条页可以前后切换词条。
- 第四单元完成页能回到训练或学习路径。
- 答错时有明确但温和的复习提示。
- 手机宽度下按钮和中文说明不明显重叠。
- 没有真实音频文件时，页面不会假装播放成功。
- 现有审校原则不被破坏。

## 测试方案

自动检查：

- 用 Node 测试确认四个单元标题、步骤、完成入口存在。
- 确认前后切换按钮渲染在字母、组合、词条页面。
- 确认 AI 临时音频提示仍存在。
- 确认家庭称呼仍包含待审校和不设唯一答案说明。

手动 / 渲染检查：

- 直接打开 `prototype/index.html`。
- 从首页进入学习路径。
- 点开四个单元。
- 每个单元至少进入一个详情页。
- 点击一次选择题错误答案，确认反馈温和。
- 在手机宽度视觉检查文字是否挤压。
