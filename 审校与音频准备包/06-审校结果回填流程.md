# 审校结果回填流程

## 这个文件解决什么问题

前面的文件已经准备好了审校总表和录音清单。

这个文件说明：拿到母语者反馈之后，怎样把结果回填到项目里。

当前原型已经有一个 `审校看板` 页面。它可以帮助项目创建者先在界面里模拟回填状态，看清哪些内容已经通过、哪些还要修改、哪些只是展示不考核、哪些是变体保留、哪些音频还没录。

## 进入审校看板

入口有两个：

- 首页快速入口：`审校看板`
- 我的页面：`审校看板`

## 审校状态含义

| 状态 | 什么时候使用 |
| --- | --- |
| 待审校 | 还没有母语者确认 |
| 通过 | 已确认可以进入正式课程 |
| 需修改 | 词形、转写、中文或说明需要改 |
| 只展示不考核 | 可以给学习者看，但不能作为题目标准答案 |
| 变体保留 | 属于地区 / 家庭 / 口语变体，需要和标准主词分开 |
| 待二审 | 第一位审校者不确定，需要第二位母语者确认 |

## 音频状态含义

| 状态 | 什么时候使用 |
| --- | --- |
| 真人音频待录制 | 还没有录音 |
| AI 临时音频 | 使用 AI 生成的临时音频，只用于内部测试流程 |
| 真人音频已录制 | 文件已经由真人录好，但还没有接入页面 |
| 真人音频已接入 | 文件已经放到项目并能被页面引用 |
| 需重新录制 | 音频读错、噪音明显、口音不合适或文字已修改 |

## 推荐回填步骤

1. 打开 `02-审校总表.md`。
2. 请母语者逐条确认。
3. 打开原型里的 `审校看板`。
4. 选择对应项目。
5. 点击审校状态。
6. 点击音频状态。
7. 把正式结果同步回 Markdown 文件。

如果当前使用 AI 音频，请选择 `AI 临时音频`，不要选择真人状态。

## 家庭称呼专项

这些项目必须重点看：

- `ئانا`
- `ئاپا`
- `ئاتا`
- `دادا`

它们不能设唯一答案。

看板里这些内容会作为家庭 / 基础称呼重点项显示。母语者审校后要确认：

- 哪个是标准语主词
- 哪个是家庭口语
- 哪个是地区说法
- 哪些可以作为可接受答案
- 哪些只展示不考核

## 当前限制

当前看板是本地静态原型：

- 点击状态后，只在当前页面状态里变化。
- 刷新页面后不会永久保存。
- 正式结果必须写回 `02-审校总表.md`、课程文档和代码数据。

后续可以继续升级：

- 保存到浏览器本地存储
- 导出审校结果
- 从 Markdown 或 JSON 导入结果
- 接入真实音频文件
- 自动生成待修改清单
