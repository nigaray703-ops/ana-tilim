# 给母语者的审校说明

## 项目背景

Ana Tilim 是一个面向零基础学习者的维吾尔语学习原型。当前重点是标准维吾尔语的字母、基础组合、基础词形和听说书写练习。

请审校者优先帮忙确认：

- 字母和转写提示是否合适
- 发音提示是否容易误导
- 组合是否适合作为新手练习
- 词形是否是标准维吾尔语
- 中文预览是否准确
- 哪些是地区 / 家庭口语变体
- 哪些内容可以进入考核
- 哪些内容只能展示，不能考核
- 录音时应该读哪一个准确词形

## 审校总原则

主线统一按标准维吾尔语设计。

如果某个说法在南疆、北疆、家庭口语或不同地区有差异，请不要直接删除；请标注它属于哪一种情况。

建议使用这些审校结果：

| 结果 | 含义 |
| --- | --- |
| 审校通过 | 可以进入正式课程 |
| 需修改 | 词形、转写、中文或说明需要修改 |
| 只展示不考核 | 可以给学习者看，但不要作为答题标准 |
| 变体保留 | 是地区 / 家庭 / 口语变体，需要和标准主词分开 |
| 暂不使用 | 不适合当前阶段 |
| 待二审 | 审校者不确定，需要第二位母语者确认 |

## 审校时请特别注意

### 1. 字母

请确认：

- 32 个字母顺序是否适合标准字母表展示
- 转写提示是否适合新手
- 元音组 `ئا / ئە / ئو / ئۇ / ئۆ / ئۈ / ئې / ئى` 的说明是否正确
- `ئ` 的说明是否准确，是否应该在当前阶段讲得更简单
- 哪些字母后面通常不继续连接的说明是否准确

### 2. 组合

第二单元里的 `با / پا / تا / نا / لا / ما` 等内容先作为组合练习。

请确认：

- 这些组合是否适合作为新手练习
- 转写提示是否需要调整
- 哪些组合如果也是词，需要不要在本阶段讲词义
- 三字母慢读 `بال / مان / نان / تال` 是否适合作为练习材料

### 3. 基础词形

第三单元所有词条现在都是候选词条，状态是 `待母语者审校`。

请确认：

- 词形是否标准
- 中文预览是否准确
- 转写提示是否合适
- 使用场景是否需要说明
- 是否可以考中文含义
- 是否只能练词形，不考含义

### 4. 家庭 / 基础称呼

用户已经提醒：

- 妈妈不仅仅是 `ئانا`，也可能是 `ئاپا`
- 爸爸不仅仅是 `ئاتا`，也可能是 `دادا`

请审校者帮忙分清：

- 哪个是标准语主词
- 哪个是家庭口语
- 哪个是地区说法
- 哪些可以作为可接受答案
- 哪些只展示不考核
- 题目里是否应该允许多个答案

这一类绝对不要设成唯一答案。

### 5. 音频

录音前请先确认文字。

请审校者确认：

- 录音者应该读哪个词形
- 是否需要慢速版
- 是否需要自然语速版
- 组合词或完整句子是否要拆成短句录

当前项目只保留真人音频。请把已接入音频当作需要审听的录音素材：如果读音、噪音、语速或词形不合适，请直接标记为 `需重新录制`。

## 审校输出方式

最简单的方式：

1. 打开 `02-审校总表.md`
2. 对每一行写结果：通过 / 需修改 / 只展示不考核 / 变体保留 / 暂不使用 / 待二审
3. 如果要修改，写出正确词形和说明

也可以使用 `05-审校反馈记录模板.md` 单独记录。
