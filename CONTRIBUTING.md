# Feedback only / 仅接收反馈

This is an independent portfolio project, not a community or collaborative open-source project. **Unsolicited pull requests are not accepted.** Please do not submit source code, interface designs, curriculum content, branding, logos, or human recordings for inclusion in the official repository.

You may report a factual error, broken link, audio problem, accessibility issue, or security concern to the repository owner through the official GitHub account or the deployed website's feedback channel. The owner alone decides whether and how to make a correction.

Feedback, suggestions, corrections, discussions, pull requests, or forks do not create joint authorship, joint ownership, collaborator status, maintainer status, or permission to copy, republish, modify, or reuse this project. Do not upload confidential information, personal data, third-party copyrighted content, or human recordings.
